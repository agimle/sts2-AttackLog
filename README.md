# Attack Log

**Slay the Spire 2 Mod - 战斗统计追踪器**

## 📖 简介

Attack Log 是一个为 Slay the Spire 2 设计的模组，用于实时追踪和显示每位玩家在游戏过程中的战斗数据。无论你是单人游戏还是多人合作，都能清晰地看到每位玩家的贡献度。

## ✨ 功能特性

### 🎯 核心功能

- **实时伤害追踪** - 追踪每位玩家造成的伤害，包括：
  - 对护盾造成的伤害（没有做类型区分，不显示多少是护盾伤害多少是血量伤害）
  - 对生命值造成的伤害
  - 过量伤害（只统计了，但是目前未参与后续计算）

- **多层级数据展示**
  - **总计** - 整个运行过程中的总伤害
  - **房间** - 当前战斗房间的伤害
  - **回合** - 当前回合的伤害

- **特殊能力支持**
  - 毒药伤害追踪
  - 末日能力伤害追踪
  - 宠物伤害归属

- **数据持久化** - 自动保存运行数据，支持断线重连

### 🎨 界面特性

- **可拖动面板** - 自由调整面板位置，不遮挡游戏内容
- **实时更新** - 伤害数据实时刷新，无需手动操作
- **排序功能** - 支持按"总计"或"房间"排序玩家列表
- **伤害占比** - 显示每位玩家伤害占总伤害的百分比
- **可视化进度条** - 直观展示伤害占比

### 👥 多人游戏支持

- 完美支持多人合作模式
- 自动识别所有玩家
- 区分玩家和宠物伤害
- 独立追踪每位玩家的数据

## 📦 安装

### 前置要求

- Slay the Spire 2

### 安装步骤

1. 下载最新版本的模组压缩包
2. 定位到目录：`*\Steam\steamapps\common\Slay the Spire 2\mods` ，如果没有`mods`文件夹，先创建`mods`文件夹
3. 解压压缩包到该目录，或直接将压缩包里的 `sts2-AttackLog` 文件夹放入 `mods` 文件夹
4. 启动游戏，模组将自动加载

## 🎮 使用方法

### 基本使用

模组加载后，战斗统计面板会自动显示在屏幕右侧。面板包含以下信息：

```
┌─────────────────────────────────────┐
│ ⚔ 战斗统计           ▼ 总计        │
├─────────────────────────────────────┤
│ 玩家      占比    总计  房间  回合  │
│ ┌─────────────────────────────────┐ │
│ │ 🗡️ 铁甲战士 [战士]              │ │
│ │   45.2%    1250   320    85    │ │
│ │   ████████████░░░░░░░░░░░░░░░  │ │
│ └─────────────────────────────────┘ │
│ ┌─────────────────────────────────┐ │
│ │ 🗡️ 静默猎手 [猎人]              │ │
│ │   32.8%    910    245    62    │ │
│ │   ████████░░░░░░░░░░░░░░░░░░░  │ │
│ └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

### 面板操作

- **拖动面板** - 点击面板标题栏并拖动
- **切换排序** - 点击右上角按钮切换"总计/房间"排序

### 数据说明

| 列名 | 说明 |
|------|------|
| 占比 | 该玩家伤害占总伤害的百分比| 
| 总计 | 整个爬塔过程中的累计伤害| 
| 房间 | 当前战斗房间的伤害|
| 回合 | 当前回合的伤害|
