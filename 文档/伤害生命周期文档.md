## 一、核心数据结构

### 1.1 DamageResult - 伤害结果

伤害结果类，记录单次伤害的完整信息。

```csharp
public class DamageResult
{
    // 接受伤害的生物
    public Creature Receiver { get; }
    
    // 伤害属性
    public ValueProp Props { get; }
    
    // 被护盾格挡的伤害
    public int BlockedDamage { get; set; }
    
    // 未格挡的伤害（实际扣血）
    public int UnblockedDamage { get; init; }
    
    // 过量伤害（超过当前HP的伤害）
    public int OverkillDamage { get; init; }
    
    // 总伤害 = 格挡伤害 + 未格挡伤害
    public int TotalDamage => BlockedDamage + UnblockedDamage;
    
    // 护盾是否被打破
    public bool WasBlockBroken { get; set; }
    
    // 是否被完全格挡
    public bool WasFullyBlocked { get; set; }
    
    // 目标是否被击杀
    public bool WasTargetKilled { get; init; }
}
```

### 1.2 ValueProp - 伤害属性枚举

```csharp
[Flags]
public enum ValueProp
{
    Unblockable = 2,   // 不可格挡
    Unpowered = 4,     // 不触发能力效果
    Move = 8,          // 移动/动作
    SkipHurtAnim = 16  // 跳过受伤动画
}
```

**常用伤害属性组合**:

| 属性名 | 值 | 说明 |
|--------|-----|------|
| `card` | Move | 普通卡牌伤害 |
| `cardUnpowered` | Unpowered \| Move | 不触发能力的卡牌伤害 |
| `cardHpLoss` | Unblockable \| Unpowered \| Move | HP损失（不可格挡） |
| `monsterMove` | Move | 怪物攻击伤害 |
| `nonCardUnpowered` | Unpowered | 非卡牌的不触发能力伤害 |
| `nonCardHpLoss` | Unblockable \| Unpowered | 非卡牌HP损失 |

### 2.2 攻击执行入口

```
AttackCommand.Execute(choiceContext)
├── 检查攻击者是否存活
├── 检查战斗是否结束
├── ★ Hook.BeforeAttack(combatState, this)
├── 获取攻击次数 (ModifyAttackHitCount)
└── 循环执行每次攻击
    ├── 播放攻击者动画和特效
    ├── 确定有效目标
    ├── 播放命中特效
    └── 执行伤害 (CreatureCmd.Damage)
```

**关键代码**:
```csharp
public async Task<AttackCommand> Execute(PlayerChoiceContext? choiceContext)
{
    if (Attacker == null || Attacker.IsDead)
        return this;
    
    if (CombatManager.Instance.IsOverOrEnding)
        return this;
    
    CombatState combatState = Attacker.CombatState;
    
    // Hook: 攻击前
    await Hook.BeforeAttack(combatState, this);
    
    // 获取攻击次数
    decimal attackCount = Hook.ModifyAttackHitCount(combatState, this, _hitCount);
    
    for (int i = 0; i < attackCount; i++)
    {
        // 执行每次攻击...
        AddResultsInternal(await CreatureCmd.Damage(...));
    }
    
    // 记录战斗历史
    CombatManager.Instance.History.CreatureAttacked(combatState, Attacker, _results.ToList());
    
    // Hook: 攻击后
    await Hook.AfterAttack(combatState, this);
    
    return this;
}
```

### 3.1 伤害计算完整流程

```

│   ├── ★ Hook.AfterModifyingHpLostAfterOsty
```

### 3.2 伤害修改详解

#### 3.2.1 伤害修改公式

```
最终伤害 = min(
    (基础伤害 + 加法修改) * 乘法修改,
    伤害上限
)
```

**计算过程**:
```csharp
// 1. 加法修改
decimal additive = 0;
foreach (var model in hookListeners)
{
    additive += model.ModifyDamageAdditive(target, amount, props, dealer, cardSource);
}

// 2. 乘法修改
decimal multiplicative = 1;
foreach (var model in hookListeners)
{
    multiplicative *= model.ModifyDamageMultiplicative(target, amount, props, dealer, cardSource);
}

// 3. 计算伤害
decimal modifiedDamage = (amount + additive) * multiplicative;

// 4. 伤害上限
decimal cap = decimal.MaxValue;
foreach (var model in hookListeners)
{
    cap = Math.Min(cap, model.ModifyDamageCap(target, props, dealer, cardSource));
}

decimal finalDamage = Math.Min(modifiedDamage, cap);
```

#### 3.2.2 ModifyDamageHookType

```csharp
[Flags]
public enum ModifyDamageHookType
{
    None = 0,
    Additive = 2,        // 只执行加法修改
    Multiplicative = 4,  // 只执行乘法修改
    All = 6              // 执行所有修改
}
```

### 3.3 护盾处理

#### 3.3.1 护盾扣除逻辑

```csharp
public decimal DamageBlockInternal(decimal amount, ValueProp props)
{
    // 不可格挡的伤害直接返回0
    if (props.HasFlag(ValueProp.Unblockable))
        return 0;
    
    // 计算护盾吸收的伤害
    decimal blockedDamage = Math.Min(Block, amount);
    
    // 扣除护盾
    Block -= (int)blockedDamage;
    
    return blockedDamage;
}
```

#### 3.3.2 护盾处理流程

```
护盾处理
├── 检查是否不可格挡 (Unblockable)
│   └── 是 → blockedDamage = 0
│   └── 否 → blockedDamage = min(Block, amount)
├── 扣除护盾 Block -= blockedDamage
└── 返回格挡伤害值
```

### 3.4 HP扣除

#### 3.4.1 HP扣除逻辑

```csharp
public DamageResult LoseHpInternal(decimal amount, ValueProp props)
{
    // 判断是否会被击杀
    bool willBeKilled = CurrentHp > 0 && amount >= CurrentHp;
    int currentHp = CurrentHp;
    
    // 计算实际扣血（最大999999999）
    int damageAmount = (int)Math.Min(amount, 999999999);
    
    // 扣除HP
    CurrentHp = Math.Max(CurrentHp - damageAmount, 0);
    
    return new DamageResult(this, props)
    {
        UnblockedDamage = currentHp - CurrentHp,  // 实际扣血
        WasTargetKilled = willBeKilled,           // 是否被击杀
        OverkillDamage = willBeKilled ? Math.Max(damageAmount - currentHp, 0) : 0  // 过量伤害
    };
}
```

## 六、死亡判定流程

### 6.1 死亡判定详细流程

```
Kill(creatures)
├── 遍历所有待死亡生物
│   └── KillWithoutCheckingWinCondition(creature)
│       ├── 如果HP > 0，先扣到0
│       │   └── LoseHpInternal(currentHp)
│       ├── ★ Hook.BeforeDeath(runState, combatState, creature)
│       ├── ★ Hook.ShouldDie(runState, combatState, creature, out preventer)
│       │   ├── 返回true → 继续死亡流程
│       │   └── 返回false → 阻止死亡
│       ├── 如果允许死亡
│       │   ├── creature.InvokeDiedEvent()
│       │   ├── 检查是否从战斗移除
│       │   ├── 播放死亡动画
│       │   ├── ★ Hook.AfterDeath(runState, combatState, creature, wasRemovalPrevented, deathAnimLength)
│       │   ├── 移除所有能力
│       │   ├── 从战斗中移除
│       │   └── 如果是主要敌人，杀死所有次要敌人
│       └── 如果阻止死亡
│           ├── ★ Hook.AfterDeath(runState, combatState, creature, wasRemovalPrevented: true, 0)
│           ├── ★ Hook.AfterPreventingDeath(runState, combatState, preventer, creature)
│           └── 如果仍然死亡，递归处理
└── 检查所有玩家是否死亡
    └── 是 → LoseCombat()
```

### 6.2 死亡相关Hook

| Hook | 说明 |
|------|------|
| `BeforeDeath` | 死亡前触发 |
| `ShouldDie` | 判断是否应该死亡 |
| `AfterDeath` | 死亡后触发 |

## 七、Hook触发顺序

### 7.1 完整伤害Hook序列

```
攻击发起:
1. BeforeAttack (攻击前)
2. ModifyAttackHitCount (修改攻击次数)

3. ModifyDamageAdditive (加法修改伤害)
4. ModifyDamageMultiplicative (乘法修改伤害)
5. ModifyDamageCap (伤害上限)
6. AfterModifyingDamageAmount (伤害修改完成)

护盾和HP:
8. [护盾处理 - 内部]
9. ModifyHpLostBeforeOsty (Osty前HP损失修改)
10. AfterModifyingHpLostBeforeOsty
11. ModifyUnblockedDamageTarget (修改伤害目标)
12. ModifyHpLostAfterOsty (Osty后HP损失修改)
13. AfterModifyingHpLostAfterOsty
14. [HP扣除 - 内部]

伤害结果:
15. AfterBlockBroken (护盾打破)
16. AfterCurrentHpChanged (HP变化)
17. AfterDamageGiven (造成伤害)
18. AfterDamageReceived (受到伤害)

攻击结束:
19. AfterAttack (攻击后)

```

### 9.2 伤害来源判断

```csharp
// 在Hook中判断伤害来源
public override Task AfterDamageReceived(
    PlayerChoiceContext choiceContext, 
    Creature target, 
    DamageResult result, 
    ValueProp props, 
    Creature? dealer, 
    CardModel? cardSource)
{
    // 判断是否来自卡牌
    if (cardSource != null)
    {
        // 卡牌伤害
        string cardName = cardSource.Id.Entry;
    }
    
    // 判断攻击者类型
    if (dealer != null)
    {
        if (dealer.IsPlayer)
        {
            // 玩家造成的伤害
        }
        else if (dealer.IsEnemy)
```

## 十、数据收集建议

### 10.1 推荐监听的Hook

以下是与伤害相关的所有Hook，按功能分类：

#### 10.1.1 攻击类Hook

| Hook | 类型 | 参数 | 用途 |
|------|------|------|------|
| `BeforeAttack` | 事件 | `(CombatState combatState, AttackCommand command)` | 攻击执行前触发，可获取攻击者、目标、伤害值 |
| `AfterAttack` | 事件 | `(CombatState combatState, AttackCommand command)` | 攻击执行后触发，可获取所有伤害结果 |
| `ModifyAttackHitCount` | 修改 | `(AttackCommand attack, int hitCount)` | 修改攻击次数，返回新的攻击次数 |

**AttackCommand 关键属性**:
- `Attacker` - 攻击者生物
- `ModelSource` - 攻击来源（CardModel/MonsterModel）
- `TargetSide` - 目标方（Player/Enemy）
- `DamageProps` - 伤害属性
- `Results` - 伤害结果列表（DamageResult集合）
- `IsSingleTargeted` - 是否单体目标
- `IsMultiTargeted` - 是否多目标
- `IsRandomlyTargeted` - 是否随机目标

---

#### 10.1.2 伤害计算类Hook

| Hook | 类型 | 参数 | 用途 |
|------|------|------|------|
| `ModifyDamageAdditive` | 修改 | `(Creature? target, decimal amount, ValueProp props, Creature? dealer, CardModel? cardSource)` | 加法修改伤害值，返回增加的伤害 |
| `ModifyDamageMultiplicative` | 修改 | `(Creature? target, decimal amount, ValueProp props, Creature? dealer, CardModel? cardSource)` | 乘法修改伤害值，返回乘数 |
| `ModifyDamageCap` | 修改 | `(Creature? target, ValueProp props, Creature? dealer, CardModel? cardSource)` | 设置伤害上限，返回上限值 |
| `AfterModifyingDamageAmount` | 事件 | `(CardModel? cardSource, IEnumerable<AbstractModel> modifiers)` | 伤害修改完成后触发 |

**伤害计算公式**:
```
最终伤害 = min((基础伤害 + 加法修改总和) × 乘法修改乘积, 伤害上限)
```

---

#### 10.1.3 伤害接收类Hook

| Hook | 类型 | 参数 | 用途 |
|------|------|------|------|
| `BeforeDamageReceived` | 事件 | `(PlayerChoiceContext choiceContext, Creature target, decimal amount, ValueProp props, Creature? dealer, CardModel? cardSource)` | 生物受到伤害前触发 |
| `AfterDamageReceived` | 事件 | `(PlayerChoiceContext choiceContext, Creature target, DamageResult result, ValueProp props, Creature? dealer, CardModel? cardSource)` | 生物受到伤害后触发 |
| `AfterDamageReceivedLate` | 事件 | 同上 | 生物受到伤害后触发（延迟版） |
| `AfterDamageGiven` | 事件 | `(PlayerChoiceContext choiceContext, Creature? dealer, DamageResult result, ValueProp props, Creature target, CardModel? cardSource)` | 生物造成伤害后触发 |

**DamageResult 关键属性**:
- `Receiver` - 接受伤害的生物
- `BlockedDamage` - 被护盾格挡的伤害
- `UnblockedDamage` - 未格挡的伤害（实际扣血）
- `OverkillDamage` - 过量伤害
- `TotalDamage` - 总伤害
- `WasBlockBroken` - 护盾是否被打破
- `WasFullyBlocked` - 是否被完全格挡
- `WasTargetKilled` - 目标是否被击杀

### 10.3 数据收集示例

```csharp
public class DamageDataCollector
{
    private int _totalDamageDealt;
    private int _totalDamageTaken;
    private int _totalBlockedDamage;
    private int _killCount;
    
    public Task AfterDamageGiven(
        PlayerChoiceContext choiceContext, 
        Creature? dealer, 
        DamageResult result, 
        ValueProp props, 
        Creature target, 
        CardModel? cardSource)
    {
        if (dealer?.IsPlayer == true)
        {
            _totalDamageDealt += result.UnblockedDamage;
        }
        return Task.CompletedTask;
    }
    
    public Task AfterDamageReceived(
        PlayerChoiceContext choiceContext, 
        Creature target, 
        DamageResult result, 
        ValueProp props, 
        Creature? dealer, 
        CardModel? cardSource)
    {
        if (target.IsPlayer)
        {
            _totalDamageTaken += result.UnblockedDamage;
            _totalBlockedDamage += result.BlockedDamage;
        }
        return Task.CompletedTask;
    }
    
    public Task AfterDeath(
        IRunState runState, 
        CombatState? combatState, 
        Creature creature, 
        bool wasRemovalPrevented, 
        float deathAnimLength)
    {
        if (creature.IsEnemy && !wasRemovalPrevented)
        {
            _killCount++;
        }
        return Task.CompletedTask;
    }
}
```
