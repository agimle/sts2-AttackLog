# 增伤减伤追踪流程文档

## 概述

本文档详细描述伤害计算中每个修改节点的追踪机制——谁提供了增伤/减伤、提供了多少、在哪个阶段介入。适用于 Mod 开发中实现"伤害来源归因"功能。

---

## 一、伤害修改的三大阶段

一次攻击的伤害值经过以下三个独立阶段依次修改，每个阶段都有独立的 `modifiers` 收集机制：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          伤害修改三大阶段                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  阶段1: ModifyDamage (伤害值修改)                                           │
│  ├── 输入: baseDamage (卡牌/攻击基础伤害)                                   │
│  ├── 修改: 附魔加法 → 附魔乘法 → Hook加法 → Hook乘法 → 伤害上限            │
│  ├── 输出: modifiedAmount (修改后伤害值)                                    │
│  └── modifiers: 参与修改的所有 AbstractModel                                │
│                                                                             │
│  阶段2: ModifyHpLostBeforeOsty (Osty前HP损失修改)                           │
│  ├── 输入: unblockedDamage (修改后伤害 - 护盾吸收)                          │
│  ├── 修改: BeforeOsty → BeforeOstyLate                                     │
│  ├── 输出: 修改后HP损失                                                     │
│  └── modifiers: 参与修改的所有 AbstractModel                                │
│                                                                             │
│  阶段3: ModifyHpLostAfterOsty (Osty后HP损失修改)                            │
│  ├── 输入: 经过Osty转移后的HP损失                                           │
│  ├── 修改: AfterOsty → AfterOstyLate                                       │
│  ├── 输出: 最终HP损失                                                       │
│  └── modifiers: 参与修改的所有 AbstractModel                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 二、阶段1: ModifyDamage — 伤害值修改追踪

### 2.1 修改管线与数值追踪点

```
Hook.ModifyDamage(runState, combatState, target, dealer, damage, props,
                  cardSource, modifyDamageHookType, previewMode, out modifiers)
│
│  ★ 追踪变量: damage (当前伤害值，随管线流动)
│
├── [步骤0] 记录初始值
│   └── baseDamage = damage  (例: 6)
│
├── [步骤1] 附魔修改 (Enchantment)
│   │
│   ├── if cardSource.Enchantment != null
│   │   │
│   │   ├── [1a] 附魔加法
│   │   │   ├── enchantAdd = EnchantDamageAdditive(damage, props)
│   │   │   ├── damage += enchantAdd
│   │   │   └── ★ 追踪: Enchantment 提供加法修改 +enchantAdd
│   │   │
│   │   └── [1b] 附魔乘法
│   │       ├── enchantMul = EnchantDamageMultiplicative(damage, props)
│   │       ├── damage *= enchantMul
│   │       └── ★ 追踪: Enchantment 提供乘法修改 ×enchantMul
│   │
│   └── ★ 注意: 附魔修改不计入 modifiers 列表（仅Hook修改计入）
│
├── [步骤2] Hook加法修改 (ModifyDamageAdditive)
│   │
│   ├── 遍历 runState.IterateHookListeners(combatState) 中每个 item
│   │   ├── delta = item.ModifyDamageAdditive(target, damage, props, dealer, cardSource)
│   │   ├── damage += delta
│   │   └── if delta != 0
│   │       ├── list.Add(item)  ← ★ 记录到 modifiers
│   │       └── ★ 追踪: item.Id 提供加法修改 +delta
│   │
│   └── ★ 追踪公式: hookAddTotal = Σ(delta_i)
│
├── [步骤3] Hook乘法修改 (ModifyDamageMultiplicative)
│   │
│   ├── 遍历 runState.IterateHookListeners(combatState) 中每个 item
│   │   ├── mul = item.ModifyDamageMultiplicative(target, damage, props, dealer, cardSource)
│   │   ├── damage *= mul
│   │   └── if mul != 1
│   │       ├── list.Add(item)  ← ★ 记录到 modifiers
│   │       └── ★ 追踪: item.Id 提供乘法修改 ×mul
│   │
│   └── ★ 追踪公式: hookMulTotal = Π(mul_i)
│
├── [步骤4] 伤害上限 (ModifyDamageCap)
│   │
│   ├── cap = decimal.MaxValue
│   ├── 遍历 runState.IterateHookListeners(combatState) 中每个 item
│   │   ├── itemCap = item.ModifyDamageCap(target, props, dealer, cardSource)
│   │   ├── if itemCap < cap → cap = itemCap
│   │   └── if damage > itemCap
│   │       ├── damage = itemCap
│   │       ├── list.Add(item)  ← ★ 记录到 modifiers
│   │       └── ★ 追踪: item.Id 设置伤害上限 = itemCap
│   │
│   └── ★ 追踪: 最终上限 = min(所有itemCap)
│
└── return Math.Max(0m, damage)  →  modifiedAmount
    └── modifiers = list  →  参与修改的 AbstractModel 列表
```

### 2.2 modifiers 列表的内容

`modifiers` 是 `IEnumerable<AbstractModel>`，包含所有对伤害值产生了实际影响的模型：

| 修改类型 | 计入条件 | 记录内容 |
|----------|----------|----------|
| `ModifyDamageAdditive` | 返回值 `!= 0` | 提供增伤/减伤的模型 |
| `ModifyDamageMultiplicative` | 返回值 `!= 1` | 提供乘法修改的模型 |
| `ModifyDamageCap` | 实际限制了伤害 | 设置伤害上限的模型 |

**关键特性**：
- 同一个 `AbstractModel` 可能因加法和乘法修改被添加两次
- `modifiers` 列表是有序的，顺序与 `IterateHookListeners` 遍历顺序一致
- 附魔修改（Enchantment）**不计入** modifiers 列表

### 2.3 伤害修改公式

```
modifiedAmount = max(0, min(
    (baseDamage + enchantAdd + Σ hookAdd_i) × enchantMul × Π hookMul_j,
    min(cap_k)
))
```

**数值追踪拆解**：

| 追踪项 | 公式 | 含义 |
|--------|------|------|
| 附魔增伤 | `enchantAdd` | 附魔固定加成 |
| 附魔倍率 | `enchantMul` | 附魔乘法倍率 |
| Hook总增伤 | `Σ hookAdd_i` (delta > 0) | 所有Hook加法增伤之和 |
| Hook总减伤 | `Σ hookAdd_i` (delta < 0) | 所有Hook加法减伤之和 |
| Hook总倍率 | `Π hookMul_j` | 所有Hook乘法倍率之积 |
| 伤害上限 | `min(cap_k)` | 最严格的上限值 |

## 三、阶段2: ModifyHpLostBeforeOsty — Osty前HP损失修改追踪

### 3.1 修改管线

```
Hook.ModifyHpLostBeforeOsty(runState, combatState, target, amount, props,
                            dealer, cardSource, out modifiers)
│
│  ★ 输入: amount = max(modifiedAmount - blockedDamage, 0)  (未格挡伤害)
│
├── [步骤1] 常规阶段 (ModifyHpLostBeforeOsty)
│   │
│   ├── 遍历 runState.IterateHookListeners(combatState) 中每个 item
│   │   ├── prev = amount
│   │   ├── amount = item.ModifyHpLostBeforeOsty(target, amount, props, dealer, cardSource)
│   │   └── if Truncate(prev) != Truncate(amount)
│   │       ├── list.Add(item)  ← ★ 记录到 modifiers
│   │       └── ★ 追踪: item.Id 修改HP损失 prev → amount (delta = amount - prev)
│   │
│   └── ★ 判断条件: 取整后不同即计入（非零判断）
│
├── [步骤2] Late阶段 (ModifyHpLostBeforeOstyLate)
│   │
│   ├── 遍历 runState.IterateHookListeners(combatState) 中每个 item
│   │   ├── prev = amount
│   │   ├── amount = item.ModifyHpLostBeforeOstyLate(target, amount, props, dealer, cardSource)
│   │   └── if Truncate(prev) != Truncate(amount)
│   │       ├── list.Add(item)  ← ★ 记录到 modifiers
│   │       └── ★ 追踪: item.Id 修改HP损失 prev → amount (delta = amount - prev)
│   │
│   └── ★ Late阶段在常规阶段之后执行，可覆盖常规修改结果
│
└── return amount  →  修改后HP损失
    └── modifiers = list
```

### 3.2 与 ModifyDamage 的追踪差异

| 差异点 | ModifyDamage | ModifyHpLostBeforeOsty |
|--------|-------------|----------------------|
| 判断条件 | `delta != 0` (精确比较) | `Truncate(prev) != Truncate(amount)` (取整比较) |
| 修改类型 | 加法/乘法/上限分离 | 直接修改amount值 |
| 阶段划分 | 单阶段 | 常规 + Late 两阶段 |
| 附魔参与 | 是 | 否 |

```
│
└── return amount  →  最终HP损失
    └── modifiers = list
```

## 五、Hook监听者遍历顺序 (IterateHookListeners)

理解遍历顺序对于追踪"谁先修改了伤害"至关重要。

### 5.1 RunState.IterateHookListeners 顺序

```
RunState.IterateHookListeners(combatState)
│
├── 1. 所有玩家的牌组中的卡牌 (Deck.Cards)
│   └── 每张卡: CardModel + Enchantment (如果有)
│
├── 2. [仅 combatState == null 时] 所有玩家的遗物和药水
│   ├── Relics (未融化的)
│   └── Potions
│
├── 3. [仅 combatState == null 时] RunState.Modifiers + MultiplayerScalingModel
│
├── 4. ModHelper.IterateAllRunStateSubscribers
│
└── 5. [combatState != null 时] → 委托给 CombatState.IterateHookListeners()
```

### 5.2 CombatState.IterateHookListeners 顺序

```
CombatState.IterateHookListeners()
│
├── 遍历 _allies + _enemies (先友方后敌方)
│   │
│   ├── 对每个 Creature:
│   │   ├── 1. creature.Powers (所有能力)
│   │   │
│   │   ├── 2a. 如果是怪物: creature.Monster
│   │   │
│   │   └── 2b. 如果是玩家:
│   │       ├── player.Relics (未融化的)
│   │       ├── player.PotionSlots (非空的)
│   │       ├── playerCombatState.OrbQueue.Orbs (球体)
│   │       └── playerCombatState.AllPiles 中所有卡牌
│   │           ├── CardModel
│   │           ├── CardModel.Affliction (如果有)
│   │           └── CardModel.Enchantment (如果有)
│   │
│   └── ★ Powers 在 Relics 之前，意味着能力先于遗物修改伤害
│
├── CombatState.Modifiers
│
├── CombatState.MultiplayerScalingModel (如果有)
│
└── ModHelper.IterateAllCombatStateSubscribers
```

### 5.3 完整遍历顺序总结

```
[RunState层]
  1. 玩家1牌组卡牌 + 附魔
  2. 玩家2牌组卡牌 + 附魔
  ...
  [CombatState层]
  3. 玩家1 Creature的 Powers
  4. 玩家1的 Relics
  5. 玩家1的 Potions
  6. 玩家1的 Orbs
  7. 玩家1手牌/弃牌堆/抽牌堆中卡牌 + Affliction + Enchantment
  8. 玩家1的宠物 Creature的 Powers
  9. 敌人1 Creature的 Powers
  10. 敌人1的 Monster
  11. 敌人2 Creature的 Powers
  12. 敌人2的 Monster
  ...
  13. CombatState.Modifiers
  14. MultiplayerScalingModel
  15. Mod Subscribers
```

## 七、Mod开发：追踪增伤减伤的实现方案

### 7.1 方案一：Hook AfterModifyingDamageAmount（推荐）

游戏在 `CreatureCmd.Damage` 中已经内置了 `modifiers` 收集机制，并在修改完成后调用 `AfterModifyingDamageAmount` 传递这些信息。

```csharp
public class DamageTracker : AbstractModel
{
    public override Task AfterModifyingDamageAmount(CardModel? cardSource)
    {
        // 此时 this 已在 modifiers 列表中（如果它修改了伤害）
        // 但我们无法直接获取 modifiers 列表和具体修改量
        // 需要配合方案二
        return Task.CompletedTask;
    }
}
```

**局限**：`AfterModifyingDamageAmount` 只通知"谁修改了"，不传递"修改了多少"。

### 7.2 方案二：在 ModifyDamageAdditive/Multiplicative 中记录（推荐）

在每个修改点记录修改量和修改者：

```csharp
public class DamageModificationRecord
{
    public AbstractModel Modifier { get; set; }    // 谁修改了
    public string ModifierId { get; set; }          // 修改者ID
    public string ModificationType { get; set; }    // "Additive" / "Multiplicative" / "Cap"
    public decimal DeltaValue { get; set; }         // 修改量（加法为±N，乘法为×N）
    public decimal BeforeValue { get; set; }        // 修改前伤害
    public decimal AfterValue { get; set; }         // 修改后伤害
    public int Order { get; set; }                  // 遍历顺序
}

public class DamageTracker : AbstractModel
{
    private List<DamageModificationRecord> _records = new();

    public override decimal ModifyDamageAdditive(Creature? target, decimal amount,
        ValueProp props, Creature? dealer, CardModel? cardSource)
    {
        // 在自己的修改点记录（但不修改伤害）
        // 问题：我们只能看到自己的调用，看不到其他模型的调用
        return 0m;
    }
}
```

**局限**：每个 `AbstractModel` 只能看到自己的修改调用，无法看到其他模型的修改。

### 7.3 方案三：包装 Hook.ModifyDamage（最佳方案）

通过在 `CreatureCmd.Damage` 调用链中拦截 `Hook.ModifyDamage`，完整记录所有修改：

```csharp
public static class DamageModificationTracker
{
    public class ModificationEntry
    {
        public AbstractModel Modifier;       // 修改者
        public string ModifierName;          // 修改者名称
        public string Type;                  // "EnchantAdd" / "EnchantMul" / "HookAdd" / "HookMul" / "Cap"
        public decimal Delta;                // 修改量
        public decimal ValueBefore;          // 修改前值
        public decimal ValueAfter;           // 修改后值
        public int IterationOrder;           // 遍历顺序
    }

    public class AttackDamageLog
    {
        public decimal BaseDamage;                           // 基础伤害
        public decimal EnchantAdditive;                      // 附魔加法
        public decimal EnchantMultiplicative;                // 附魔乘法
        public List<ModificationEntry> HookAdditive = new(); // Hook加法修改列表
        public List<ModificationEntry> HookMultiplicative = new(); // Hook乘法修改列表
        public List<ModificationEntry> DamageCap = new();    // 伤害上限列表
        public decimal FinalModifiedDamage;                  // 最终修改后伤害
        public decimal BlockedDamage;                        // 护盾吸收
        public List<ModificationEntry> HpLostBeforeOsty = new(); // Osty前HP损失修改
        public List<ModificationEntry> HpLostAfterOsty = new();  // Osty后HP损失修改
        public decimal FinalHpLost;                          // 最终HP损失
    }

    /// <summary>
    /// 替代 Hook.ModifyDamage 的追踪版本
    /// </summary>
    public static decimal ModifyDamageWithTracking(
        IRunState runState, CombatState? combatState,
        Creature? target, Creature? dealer,
        decimal damage, ValueProp props, CardModel? cardSource,
        ModifyDamageHookType hookType, AttackDamageLog log)
    {
        decimal current = damage;
        log.BaseDamage = damage;

        // 1. 附魔修改
        if (cardSource?.Enchantment != null)
        {
            if (hookType.HasFlag(ModifyDamageHookType.Additive))
            {
                decimal before = current;
                decimal enchantAdd = cardSource.Enchantment.EnchantDamageAdditive(current, props);
                current += enchantAdd;
                log.EnchantAdditive = enchantAdd;
                // ★ 追踪: 附魔加法 +enchantAdd (before → current)
            }
            if (hookType.HasFlag(ModifyDamageHookType.Multiplicative))
            {
                decimal before = current;
                decimal enchantMul = cardSource.Enchantment.EnchantDamageMultiplicative(current, props);
                current *= enchantMul;
                log.EnchantMultiplicative = enchantMul;
                // ★ 追踪: 附魔乘法 ×enchantMul (before → current)
            }
        }

        // 2. Hook加法修改
        if (hookType.HasFlag(ModifyDamageHookType.Additive))
        {
            int order = 0;
            foreach (AbstractModel item in runState.IterateHookListeners(combatState))
            {
                decimal before = current;
                decimal delta = item.ModifyDamageAdditive(target, current, props, dealer, cardSource);
                current += delta;
                if (delta != 0m)
                {
                    log.HookAdditive.Add(new ModificationEntry
                    {
                        Modifier = item,
                        ModifierName = item.Id.Entry,
                        Type = "HookAdd",
                        Delta = delta,
                        ValueBefore = before,
                        ValueAfter = current,
                        IterationOrder = order++
                    });
                }
            }
        }

        // 3. Hook乘法修改
        if (hookType.HasFlag(ModifyDamageHookType.Multiplicative))
        {
            int order = 0;
            foreach (AbstractModel item in runState.IterateHookListeners(combatState))
            {
                decimal before = current;
                decimal mul = item.ModifyDamageMultiplicative(target, current, props, dealer, cardSource);
                current *= mul;
                if (mul != 1m)
                {
                    log.HookMultiplicative.Add(new ModificationEntry
                    {
                        Modifier = item,
                        ModifierName = item.Id.Entry,
                        Type = "HookMul",
                        Delta = mul,
                        ValueBefore = before,
                        ValueAfter = current,
                        IterationOrder = order++
                    });
                }
            }
        }

        // 4. 伤害上限
        {
            decimal cap = decimal.MaxValue;
            int order = 0;
            foreach (AbstractModel item in runState.IterateHookListeners(combatState))
            {
                decimal itemCap = item.ModifyDamageCap(target, props, dealer, cardSource);
                if (itemCap < cap)
                {
                    cap = itemCap;
                    if (current > itemCap)
                    {
                        decimal before = current;
                        current = itemCap;
                        log.DamageCap.Add(new ModificationEntry
                        {
                            Modifier = item,
                            ModifierName = item.Id.Entry,
                            Type = "Cap",
                            Delta = itemCap,
                            ValueBefore = before,
                            ValueAfter = current,
                            IterationOrder = order++
                        });
                    }
                }
            }
        }

        log.FinalModifiedDamage = Math.Max(0m, current);
        return log.FinalModifiedDamage;
    }

    /// <summary>
    /// 追踪 ModifyHpLostBeforeOsty
    /// </summary>
    public static decimal TrackHpLostBeforeOsty(
        IRunState runState, CombatState? combatState,
        Creature target, decimal amount, ValueProp props,
        Creature? dealer, CardModel? cardSource, AttackDamageLog log)
    {
        decimal current = amount;
        int order = 0;

        foreach (AbstractModel item in runState.IterateHookListeners(combatState))
        {
            decimal before = current;
            current = item.ModifyHpLostBeforeOsty(target, current, props, dealer, cardSource);
            if (decimal.Truncate(before) != decimal.Truncate(current))
            {
                log.HpLostBeforeOsty.Add(new ModificationEntry
                {
                    Modifier = item,
                    ModifierName = item.Id.Entry,
                    Type = "BeforeOsty",
                    Delta = current - before,
                    ValueBefore = before,
                    ValueAfter = current,
                    IterationOrder = order++
                });
            }
        }

        foreach (AbstractModel item in runState.IterateHookListeners(combatState))
        {
            decimal before = current;
            current = item.ModifyHpLostBeforeOstyLate(target, current, props, dealer, cardSource);
            if (decimal.Truncate(before) != decimal.Truncate(current))
            {
                log.HpLostBeforeOsty.Add(new ModificationEntry
                {
                    Modifier = item,
                    ModifierName = item.Id.Entry,
                    Type = "BeforeOstyLate",
                    Delta = current - before,
                    ValueBefore = before,
                    ValueAfter = current,
                    IterationOrder = order++
                });
            }
        }

        return current;
    }

    /// <summary>
    /// 追踪 ModifyHpLostAfterOsty
    /// </summary>
    public static decimal TrackHpLostAfterOsty(
        IRunState runState, CombatState? combatState,
        Creature target, decimal amount, ValueProp props,
        Creature? dealer, CardModel? cardSource, AttackDamageLog log)
    {
        decimal current = amount;
        int order = 0;

        foreach (AbstractModel item in runState.IterateHookListeners(combatState))
        {
            decimal before = current;
            current = item.ModifyHpLostAfterOsty(target, current, props, dealer, cardSource);
            if (decimal.Truncate(before) != decimal.Truncate(current))
            {
                log.HpLostAfterOsty.Add(new ModificationEntry
                {
                    Modifier = item,
                    ModifierName = item.Id.Entry,
                    Type = "AfterOsty",
                    Delta = current - before,
                    ValueBefore = before,
                    ValueAfter = current,
                    IterationOrder = order++
                });
            }
        }

        foreach (AbstractModel item in runState.IterateHookListeners(combatState))
        {
            decimal before = current;
            current = item.ModifyHpLostAfterOstyLate(target, current, props, dealer, cardSource);
            if (decimal.Truncate(before) != decimal.Truncate(current))
            {
                log.HpLostAfterOsty.Add(new ModificationEntry
                {
                    Modifier = item,
                    ModifierName = item.Id.Entry,
                    Type = "AfterOstyLate",
                    Delta = current - before,
                    ValueBefore = before,
                    ValueAfter = current,
                    IterationOrder = order++
                });
            }
        }

        log.FinalHpLost = current;
        return current;
    }
}
```

### 7.4 方案四：利用 AfterDamageGiven/AfterDamageReceived 回推（补充方案）

如果无法拦截 `Hook.ModifyDamage`，可以在伤害完成后通过对比推算：

```csharp
public class DamageTracker : AbstractModel
{
    public override Task AfterDamageReceived(PlayerChoiceContext choiceContext,
        Creature target, DamageResult result, ValueProp props,
        Creature? dealer, CardModel? cardSource)
    {
        // 可获取的信息:
        // - result.TotalDamage: 总伤害
        // - result.BlockedDamage: 格挡伤害
        // - result.UnblockedDamage: 未格挡伤害
        // - result.WasTargetKilled: 是否击杀
        // - cardSource: 卡牌来源（可获取基础伤害值）
        // - dealer: 攻击者
        // - target: 受伤者

        // 推算增伤减伤:
        decimal baseDamage = cardSource?.DynamicVars.Damage.BaseValue ?? 0;
        decimal totalModification = result.TotalDamage - baseDamage;

        // 但无法区分具体是哪个修改者贡献了多少
        return Task.CompletedTask;
    }
}
```

## 八、完整追踪示例

### 8.1 场景：玩家用打击攻击易伤敌人

**初始状态**：
- 打击基础伤害: 6
- 玩家有力量+3 (StrengthPower)
- 玩家有打击假人 (StrikeDummy, +3)
- 敌人有易伤 (VulnerablePower, ×1.5)
- 打击有Sharp附魔 (+2)

**追踪过程**：

```
阶段1: ModifyDamage
│
├── baseDamage = 6
│
├── [附魔加法] Sharp: +2 → damage = 8
│   └── 追踪: Enchantment "Sharp" 加法 +2 (6→8)
│
├── [附魔乘法] 无 → damage = 8
│
├── [Hook加法] 遍历顺序:
│   ├── StrengthPower: delta = +3 → damage = 11
│   │   └── 追踪: Power "Strength" 加法 +3 (8→11)
│   └── StrikeDummy: delta = +3 → damage = 14
│       └── 追踪: Relic "StrikeDummy" 加法 +3 (11→14)
│
├── [Hook乘法] 遍历顺序:
│   └── VulnerablePower: mul = 1.5 → damage = 21
│       └── 追踪: Power "Vulnerable" 乘法 ×1.5 (14→21)
│
├── [伤害上限] 无限制 → damage = 21
│
└── modifiedAmount = 21

阶段2: ModifyHpLostBeforeOsty
│
├── 假设敌人无护盾: blockedDamage = 0, unblockedDamage = 21
├── 无修改者 → amount = 21
│
└── hpLost = 21

阶段3: ModifyHpLostAfterOsty
│
├── 无修改者 → amount = 21
│
└── finalHpLost = 21

最终结果:
├── TotalDamage = 21
├── 增伤来源:
│   ├── Sharp附魔: +2 (加法)
│   ├── StrengthPower: +3 (加法)
│   ├── StrikeDummy: +3 (加法)
│   └── VulnerablePower: ×1.5 (乘法, +7)
├── 减伤来源: 无
└── 净增伤: +15 (从6到21)
```

### 8.2 场景：虚弱玩家攻击有虚体的敌人

**初始状态**：
- 基础伤害: 10
- 玩家有虚弱 (WeakPower, ×0.75)
- 敌人有虚体 (IntangiblePower, Cap=1)

**追踪过程**：

```
阶段1: ModifyDamage
│
├── baseDamage = 10
│
├── [Hook加法] 无 → damage = 10
│
├── [Hook乘法]
│   └── WeakPower: mul = 0.75 → damage = 7.5
│       └── 追踪: Power "Weak" 乘法 ×0.75 (10→7.5) ← 减伤
│
├── [伤害上限]
│   └── IntangiblePower: cap = 1 → damage = 1
│       └── 追踪: Power "Intangible" 上限 =1 (7.5→1) ← 减伤
│
└── modifiedAmount = 1

阶段2: ModifyHpLostBeforeOsty
└── 无修改 → hpLost = 1

阶段3: ModifyHpLostAfterOsty
│
├── IntangiblePower: min(1, 1) = 1 → 无变化（不记录）
│
└── finalHpLost = 1

最终结果:
├── TotalDamage = 1
├── 增伤来源: 无
├── 减伤来源:
│   ├── WeakPower: ×0.75 (减2.5)
│   └── IntangiblePower: 上限1 (减6.5)
└── 净减伤: -9 (从10到1)
```

## 九、增伤减伤分类总结

### 9.1 增伤分类

| 类别 | 修改阶段 | 修改方式 | 典型代表 |
|------|----------|----------|----------|
| **固定加伤** | ModifyDamage | 加法 (+N) | StrengthPower, VigorPower, LeadershipPower, AccuracyPower, StrikeDummy |
| **条件加伤** | ModifyDamage | 加法 (+N) | CalcifyPower (Osty攻击), PhantomBladesPower ( Shiv连击), MysticLighter (附魔卡), MiniatureCannon (升级卡) |
| **倍率增伤** | ModifyDamage | 乘法 (×N) | VulnerablePower, DoubleDamagePower, PenNib, FlankingPower, KnockdownPower, SlowPower |
| **最低伤害提升** | HpLostBeforeOsty | 设最低值 | TheBoot |

### 9.2 减伤分类

| 类别 | 修改阶段 | 修改方式 | 典型代表 |
|------|----------|----------|----------|
| **倍率减伤** | ModifyDamage | 乘法 (×N<1) | WeakPower, SoarPower |
| **伤害上限** | ModifyDamage | 设上限 | IntangiblePower, SlipperyPower, HardToKillPower |
| **HP损失减少** | HpLostAfterOsty | 减法 (-N) | TungstenRod |
| **HP损失上限** | HpLostAfterOsty | 设上限 | IntangiblePower (双重作用) |
| **每回合受伤上限** | HpLostBeforeOsty(Late) | 设上限 | HardenedShellPower |
| **完全免疫** | HpLostAfterOsty(Late) | 归零 | BufferPower |

### 9.3 增伤减伤作用阶段速查

```
                    增伤                              减伤
                 ──────────                        ──────────
ModifyDamage:   StrengthPower (+N)                WeakPower (×0.75)
                VigorPower (+N)                   SoarPower (×<1)
                LeadershipPower (+N)              IntangiblePower (Cap=1)
                AccuracyPower (+N)                SlipperyPower (Cap=N)
                StrikeDummy (+N)                  HardToKillPower (Cap=N)
                VulnerablePower (×1.5)
                DoubleDamagePower (×2)
                PenNib (×2)
                ...

HpLostBefore:   TheBoot (最低值↑)                 HardenedShellPower (上限↓)

HpLostAfter:                                     TungstenRod (-N)
                                                  IntangiblePower (上限↓)
                                                  BufferPower (归零)
```
