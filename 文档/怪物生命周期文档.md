# 怪物生命周期文档

## 概述

本文档详细描述了杀戮尖塔2（Slay the Spire 2）战斗中怪物的完整生命周期，包括怪物创建、进入战斗、战斗中生成、死亡等各个阶段的详细过程。

## 一、怪物创建阶段

### 1.1 Encounter 生成怪物

**触发时机**: 进入战斗房间时

**主要流程**:
```
CombatRoom.StartCombat(runState)
├── Encounter.GenerateMonstersWithSlots(runState)
│   ├── 创建随机数生成器
│   └── 调用 GenerateMonsters() 生成怪物列表
├── 预加载战斗资源
├── 遍历 Encounter.MonstersWithSlots
│   ├── CombatState.CreateCreature(monster, side, slot)
│   │   ├── 创建 Creature 实例
│   │   ├── 设置唯一 HP 值 (SetUniqueMonsterHpValue)
│   │   ├── 多人游戏 HP 缩放
│   │   └── 分配 CombatId
│   └── CombatState.AddCreature(creature)
└── CombatManager.SetUpCombat(CombatState)
```

**关键代码**:
```csharp
// EncounterModel.cs
public void GenerateMonstersWithSlots(IRunState runState)
{
    AssertMutable();
    if (_monstersWithSlots != null)
    {
        throw new InvalidOperationException("Monsters have already been generated for this encounter.");
    }
    uint seed = (uint)((int)runState.Rng.Seed + runState.TotalFloor + StringHelper.GetDeterministicHashCode(Id.Entry));
    _rng = new Rng(seed);
    _monstersWithSlots = GenerateMonsters();
}

// CombatRoom.cs
private async Task StartCombat(IRunState? runState)
{
    if (!Encounter.HaveMonstersBeenGenerated)
    {
        Encounter.GenerateMonstersWithSlots(CombatState.RunState);
    }
    foreach (var (monsterModel, slot) in Encounter.MonstersWithSlots)
    {
        Creature creature = CombatState.CreateCreature(monsterModel, CombatSide.Enemy, slot);
        CombatState.AddCreature(creature);
    }
}
```

### 1.2 Creature 创建过程

```
CombatState.CreateCreature(monster, side, slot)
├── monster.AssertMutable()
├── 设置 monster.RunRng
├── new Creature(monster, side, slot)
│   ├── 设置 MaxHp = MaxInitialHp
│   ├── 设置 CurrentHp = MaxHp
│   ├── 设置 Side = CombatSide.Enemy
│   └── Monster.Creature = this
├── SetUniqueMonsterHpValue (设置唯一HP)
├── ScaleMonsterHpForMultiplayer (多人游戏缩放)
├── AttachCreature(creature)
│   ├── creature.CombatState = this
│   └── creature.CombatId = _nextCreatureId++
└── 返回 creature
```

**关键属性**:
| 属性 | 说明 |
|------|------|
| `CombatId` | 战斗中唯一标识符 |
| `SlotName` | 怪物槽位名称 |
| `Side` | CombatSide.Enemy |
| `MaxHp` | 最大生命值 |
| `CurrentHp` | 当前生命值 |
| `Monster` | MonsterModel 引用 |

## 二、战斗初始化阶段

### 2.1 战斗设置 (SetUpCombat)

**触发时机**: 战斗房间加载完成后

```
CombatManager.SetUpCombat(CombatState state)
├── _state = state
├── MultiplayerScalingModel?.OnCombatEntered(state)
├── StateTracker.SetState(state)
├── 清空额外回合列表
├── 遍历玩家
│   ├── player.ResetCombatState()
│   └── player.PopulateCombatState()
├── 遍历所有生物
│   └── AddCreature(creature)
└── 触发 CombatSetUp 事件
```

### 2.2 添加怪物到战斗

```
CombatManager.AddCreature(Creature creature)
├── 检查 creature 是否在 CombatState 中
├── creature.Monster?.SetUpForCombat()
│   ├── 生成移动状态机 (MoveStateMachine)
│   └── SpawnedThisTurn = true
├── 按槽位排序敌人 (如果有 SlotName)
├── StateTracker.Subscribe(creature)
└── 触发 CreaturesChanged 事件
```

**关键代码**:
```csharp
// MonsterModel.cs
public void SetUpForCombat()
{
    MoveStateMachine = GenerateMoveStateMachine();

### 2.3 怪物添加后处理

```
CombatManager.AfterCreatureAdded(Creature creature)
├── creature.AfterAddedToRoom()

└── 如果当前是玩家回合且是敌人
    └── Monster.RollMove(players) (滚动意图)

## 三、战斗中生成怪物

### 3.1 生成新怪物的方法

**CreatureCmd.Add 方法**:
```csharp
// CreatureCmd.cs
public static async Task<Creature> Add<T>(CombatState combatState, string? slotName = null) where T : MonsterModel
{
    Creature creature = combatState.CreateCreature(ModelDb.Monster<T>().ToMutable(), CombatSide.Enemy, slotName);
    await Add(creature);
    return creature;
}

public static async Task Add(MonsterModel monster, CombatState combatState, CombatSide side = CombatSide.Enemy, string? slotName = null)
{
    monster.AssertMutable();
    Creature creature = combatState.CreateCreature(monster, side, slotName);
    await Add(creature);
}

public static async Task Add(Creature creature)
{
    CombatState combatState = creature.CombatState;
    combatState.AddCreature(creature);
    CombatManager.Instance.AddCreature(creature);
    NCombatRoom.Instance?.AddCreature(creature);
    await CombatManager.Instance.AfterCreatureAdded(creature);
    if (combatState.CurrentSide != CombatSide.Enemy && creature.IsMonster)
    {
        creature.PrepareForNextTurn(combatState.Players.Select(p => p.Creature), rollNewMove: false);
    }
    await Hook.AfterCreatureAddedToCombat(creature.CombatState, creature);
}
```

### 3.3 SpawnedThisTurn 标志

**用途**: 标记怪物是否在当前回合生成

**效果**:
- 生成的怪物在当前回合不执行动作
- 回合结束时自动重置为 false

```csharp
// MonsterModel.cs
public bool SpawnedThisTurn { get; private set; }

// Creature.cs
public async Task TakeTurn()
{
    if (!Monster.SpawnedThisTurn)
    {
        await Monster.PerformMove();
    }
}

// MonsterModel.cs
public void OnSideSwitch()
{
    SpawnedThisTurn = false;
}
```

## 五、怪物死亡阶段

### 5.1 死亡触发方式

**方式一: 伤害致死**
```
CreatureCmd.Damage() → DamageResult.WasTargetKilled = true → Kill(creature)
```

**方式二: 直接击杀**
```
CreatureCmd.Kill(creature) 或 CreatureCmd.Kill(creatures)
```

**方式三: 末日击杀**
```
DoomPower.DoomKill() → CreatureCmd.Kill()
```

### 5.2 死亡流程详解

```
CreatureCmd.Kill(IReadOnlyCollection<Creature> creatures, bool force = false)
├── 检查是否有生物需要击杀
├── 遍历每个生物
│   └── KillWithoutCheckingWinCondition(creature, force)
├── 检查是否所有玩家死亡
│   └── 是 → LoseCombat()
└── 检查是否需要结束玩家回合
```

```
KillWithoutCheckingWinCondition(creature, force, recursion)
├── 检查 CombatState 是否存在
├── 如果 HP > 0
│   └── LoseHpInternal(HP, Unblockable|Unpowered)
├── ★ Hook.BeforeDeath(runState, combatState, creature)
├── 检查是否应该死亡
│   ├── force = true
│   ├── MaxHp <= 0
│   └── Hook.ShouldDie() 返回 true
├── 如果应该死亡
│   ├── creature.InvokeDiedEvent()
│   ├── 检查是否从战斗中移除
│   │   └── Hook.ShouldCreatureBeRemovedFromCombatAfterDeath()
│   ├── 播放死亡动画
│   │   └── nCreature.StartDeathAnim()
│   ├── ★ Hook.AfterDeath(runState, combatState, creature, wasRemovalPrevented: false, deathAnimLength)
│   ├── 从战斗中移除
│   │   ├── CombatManager.RemoveCreature(creature)
│   │   └── CombatState.RemoveCreature(creature)
│   ├── 移除所有能力
│   │   └── creature.RemoveAllPowersAfterDeath()
│   └── 检查次要敌人
│       └── 如果主要敌人死亡，杀死所有次要敌人
└── 如果死亡被阻止
    ├── ★ Hook.AfterDeath(runState, combatState, creature, wasRemovalPrevented: true, 0)
    ├── ★ Hook.AfterPreventingDeath(runState, combatState, preventer, creature)
    └── 如果仍然死亡，递归调用
```

### 5.3 死亡关键代码

```csharp
// CreatureCmd.cs
private static async Task KillWithoutCheckingWinCondition(Creature creature, bool force, int recursion = 0)
{
    await Hook.BeforeDeath(runState, combatState, creature);
    
    AbstractModel preventer = null;
    if (force || creature.MaxHp <= 0 || Hook.ShouldDie(runState, combatState, creature, out preventer))
    {
        creature.InvokeDiedEvent();
        bool shouldRemoveFromCombat = combatState != null && Hook.ShouldCreatureBeRemovedFromCombatAfterDeath(combatState, creature);
        
        // 死亡动画
        NCreature nCreature = NCombatRoom.Instance?.GetCreatureNode(creature);
        if (nCreature != null)
        {
            float deathAnimLength = nCreature.StartDeathAnim(shouldRemoveFromCombat && creature.IsMonster);
            if (shouldRemoveFromCombat && creature.IsMonster)
            {
                NCombatRoom.Instance?.RemoveCreatureNode(nCreature);
            }
        }
        
        await Hook.AfterDeath(runState, combatState, creature, wasRemovalPrevented: false, deathAnimLength);
        
        // 从战斗中移除
        if (shouldRemoveFromCombat && creature.Side == CombatSide.Enemy)
        {
            CombatManager.Instance.RemoveCreature(creature);
            if (!monster.IsPerformingMove)
            {
                combatState.RemoveCreature(creature);
            }
        }
        
        // 移除能力
        IEnumerable<PowerModel> powers = creature.RemoveAllPowersAfterDeath();
        foreach (PowerModel power in powers)
        {
            await power.AfterRemoved(creature);
        }
    }
    else
    {
        await Hook.AfterDeath(runState, combatState, creature, wasRemovalPrevented: true, 0);
        await Hook.AfterPreventingDeath(runState, combatState, preventer, creature);
        if (creature.IsDead)
        {
            await KillWithoutCheckingWinCondition(creature, force, recursion + 1);
        }
    }
}
```

### 5.4 死亡相关 Hook

| Hook | 触发时机 | 说明 |
|------|----------|------|
| `BeforeDeath` | 死亡前 | 可用于触发死亡前效果 |
| `ShouldDie` | 判断是否应该死亡 | 可阻止死亡 |
| `AfterDeath` | 死亡后 | wasRemovalPrevented 表示是否被阻止 |
| `AfterPreventingDeath` | 死亡被阻止后 | 处理复活等效果 |
| `ShouldCreatureBeRemovedFromCombatAfterDeath` | 判断是否移除 | 可阻止从战斗移除 |

## 六、怪物逃跑

### 6.1 逃跑流程

```csharp
// CreatureCmd.cs
public static Task Escape(Creature creature, bool removeCreatureNode = true)
{
    if (creature.IsDead)
    {
        return Task.CompletedTask;
    }
    
    creature.RemoveAllPowersInternalExcept();
    
    if (removeCreatureNode)
    {
        NCreature nCreature = NCombatRoom.Instance?.GetCreatureNode(creature);
        if (nCreature != null)
        {
            NCombatRoom.Instance.RemoveCreatureNode(nCreature);
            nCreature.ToggleIsInteractable(on: false);
            nCreature.Visible = false;
        }
    }
    
    CombatManager.Instance.RemoveCreature(creature);
    creature.CombatState?.CreatureEscaped(creature);
    
    return Task.CompletedTask;
}
```

### 6.2 逃跑流程图

```
CreatureCmd.Escape(creature)
├── 检查是否已死亡
├── 移除所有能力
├── 移除怪物节点
│   ├── RemoveCreatureNode()
│   ├── ToggleIsInteractable(false)
│   └── Visible = false
├── CombatManager.RemoveCreature()
└── CombatState.CreatureEscaped()
    ├── 添加到 EscapedCreatures 列表
    └── RemoveCreature()
```

## 七、怪物回合执行

### 7.1 回合执行流程

```
Monster.PerformMove()
├── 检查 CombatState 是否存在
├── 等待 0.1-0.2 秒
├── IsPerformingMove = true
├── 获取当前动作 (NextMove)
├── 记录日志
├── move.PerformMove(targets)
├── MoveStateMachine.OnMovePerformed(move)
├── CombatHistory.MonsterPerformedMove()
├── IsPerformingMove = false
├── 检查是否需要从战斗移除
│   └── 如果死亡且 ShouldCreatureBeRemovedFromCombatAfterDeath
│       └── combatState.RemoveCreature(creature)
└── 等待 0.1-0.4 秒
```

### 7.2 意图滚动

```csharp
// Creature.cs
public void PrepareForNextTurn(IEnumerable<Creature> targets, bool rollNewMove = true)
{
    Creature[] targets2 = targets.ToArray();
    if (rollNewMove)
    {
        Monster.RollMove(targets2);
    }
    NCombatRoom.Instance?.GetCreatureNode(this)?.RefreshIntents();
}

// MonsterModel.cs
public void RollMove(IEnumerable<Creature> targets)
{
    NextMove = MoveStateMachine.RollMove(targets, Creature, RunRng.MonsterAi);
}
```

| 怪物生成 | `AfterCreatureAddedToCombat` | 战斗中生成怪物 |
| 怪物死亡 | `BeforeDeath`, `AfterDeath` | 死亡前后 |
| 死亡阻止 | `AfterPreventingDeath` | 复活等效果 |
| 怪物动作 | `MonsterPerformedMoveEntry` | 通过 CombatHistory |
| 伤害数据 | `AfterDamageGiven`, `AfterDamageReceived` | 伤害相关 |

### 10.2 推荐监听的事件

| 事件 | 说明 |
|------|------|
| `Creature.Died` | 怪物死亡 |
| `Creature.Revived` | 怪物复活 |
| `CombatManager.CreaturesChanged` | 生物列表变化 |
| `CombatManager.CombatSetUp` | 战斗设置完成 |
| `CombatManager.CombatEnded` | 战斗结束 |

### 10.3 数据收集示例

```csharp
// 监听怪物生成
Hook.AfterCreatureAddedToCombat += (combatState, creature) =>
{
    if (creature.IsMonster)
    {
        Console.WriteLine($"怪物生成: {creature.Name} (ID: {creature.CombatId})");
        Console.WriteLine($"  HP: {creature.CurrentHp}/{creature.MaxHp}");
        Console.WriteLine($"  SpawnedThisTurn: {creature.Monster.SpawnedThisTurn}");
    }
};

// 监听怪物死亡
Hook.BeforeDeath += (runState, combatState, creature) =>
{
    if (creature.IsMonster)
    {
        Console.WriteLine($"怪物即将死亡: {creature.Name}");
    }
};

Hook.AfterDeath += (runState, combatState, creature, wasRemovalPrevented, deathAnimLength) =>
{
    if (creature.IsMonster)
    {
        Console.WriteLine($"怪物死亡: {creature.Name}, 被阻止: {wasRemovalPrevented}");
    }
};

// 监听 CombatHistory
CombatManager.Instance.History.Changed += () =>
{
    var lastEntry = CombatManager.Instance.History.Entries.LastOrDefault();
    if (lastEntry is MonsterPerformedMoveEntry moveEntry)
    {
        Console.WriteLine($"怪物动作: {moveEntry.Monster.Title} - {moveEntry.Move.Id}");
    }
};
```
