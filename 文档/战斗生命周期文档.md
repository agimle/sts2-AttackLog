## 一、战斗初始化阶段

### 1.1 战斗设置 (SetUpCombat)

**触发时机**: 进入战斗房间时

**主要流程**:
```
SetUpCombat(CombatState state)
├── 设置战斗状态 (_state = state)
├── 多人游戏缩放模型初始化
├── 状态追踪器初始化
├── 清空额外回合列表
├── 重置玩家战斗状态
├── 填充玩家战斗状态（牌堆洗牌等）
├── 添加所有生物到战斗
└── 触发 CombatSetUp 事件
```

**关键代码**:
```csharp
public void SetUpCombat(CombatState state)
{
    _state = state;
    _state.MultiplayerScalingModel?.OnCombatEntered(_state);
    StateTracker.SetState(state);
    
    foreach (Player player in state.Players)
    {
        player.ResetCombatState();
        player.PopulateCombatState(player.RunState.Rng.Shuffle, state);
    }
    
    foreach (Creature creature in state.Creatures)
    {
        AddCreature(creature);
    }
    
    this.CombatSetUp?.Invoke(state);
}
```

---

### 1.2 战斗房间加载完成 (AfterCombatRoomLoaded)

**触发时机**: 战斗场景加载完成后

**主要流程**:
```
AfterCombatRoomLoaded()
├── 取消之前的战斗取消令牌
├── 创建新的取消令牌
└── 启动战斗内部逻辑 (StartCombatInternal)
```

---

### 1.3 战斗开始内部逻辑 (StartCombatInternal)

**主要流程**:
```
StartCombatInternal()
├── 播放自定义音乐（如果有）
├── 遍历所有生物
│   └── AfterCreatureAdded(creature)
│       ├── creature.AfterAddedToRoom()
│       └── 敌人滚动意图（如果在玩家回合）
├── 暂停动作执行器
├── 设置战斗状态为进行中 (IsInProgress = true)
├── ★ Hook.BeforeCombatStart(runState, combatState)
├── 更新音乐轨道
├── 显示战斗开始横幅
├── 等待 0.5-1 秒
└── 开始第一个回合 (StartTurn)
```

**关键Hook**:
| Hook | 说明 |
|------|------|
| `BeforeCombatStart` | 战斗开始前触发，用于初始化遗物、能力等 |

## 二、回合开始阶段 (StartTurn)

### 2.1 回合开始总流程

```
StartTurn()
├── 确定回合类型（普通/额外回合）
├── 获取当前回合的生物列表
├── 遍历生物执行 BeforeTurnStart
├── ★ Hook.BeforeSideTurnStart(combatState, currentSide)
├── 根据当前方执行不同逻辑
│   ├── 玩家方 → 玩家回合开始
│   └── 敌方 → 敌人回合开始
└── ★ Hook.AfterSideTurnStart(combatState, currentSide)
```

---

### 2.2 玩家回合开始详细流程

```
玩家回合开始
├── 设置 PlayerActionsDisabled = false
├── 清空玩家准备状态列表
├── 显示回合横幅（非第一回合）
├── 敌人准备下一回合意图
├── 等待 0.5-0.8 秒
├── 遍历玩家生物
│   └── creature.AfterTurnStart(roundNumber, currentSide)
├── 遍历玩家生物
│   └── ★ Hook.AfterBlockCleared(combatState, creature)
├── 设置玩家回合 (SetupPlayerTurn)
│   ├── 能量重置
│   │   ├── ShouldPlayerResetEnergy 检查
│   │   ├── ResetEnergy 或 AddMaxEnergyToCurrent
│   │   └── ★ Hook.AfterEnergyReset(combatState, player)
│   ├── 抽牌
│   │   ├── ★ Hook.BeforeHandDraw(combatState, player, context)
│   │   ├── Hook.ModifyHandDraw (计算抽牌数)
│   │   ├── ★ Hook.AfterModifyingHandDraw(combatState, modifiers)
│   │   ├── 第一回合特殊处理（固有卡牌置顶）
│   │   └── CardPileCmd.Draw (抽牌)
│   └── ★ Hook.AfterPlayerTurnStart(combatState, context, player)
├── ★ Hook.AfterSideTurnStart(combatState, currentSide)
├── 球体队列回合开始处理
├── ★ Hook.BeforePlayPhaseStart(context, setupTask, combatState, player)
├── 检查胜利条件
├── 解除动作执行器暂停
├── 设置 IsPlayPhase = true
└── 触发 TurnStarted 事件
```

**关键Hook时序**:
```
BeforeSideTurnStart
    ↓
AfterTurnStart (Creature)
    ↓
AfterBlockCleared
    ↓
AfterEnergyReset
    ↓
BeforeHandDraw
    ↓
ModifyHandDraw
    ↓
AfterModifyingHandDraw
    ↓
AfterPlayerTurnStart
    ↓
AfterSideTurnStart
    ↓
BeforePlayPhaseStart
```

---

### 2.3 敌人回合开始详细流程

```
敌人回合开始
├── 设置 IsEnemyTurnStarted = true
├── 触发 TurnStarted 事件
├── 生成校验和
├── 等待解除暂停
├── 检查胜利条件
└── 执行敌人回合 (ExecuteEnemyTurn)
```

## 三、玩家出牌阶段 (Play Phase)

### 3.1 出牌阶段状态

**状态标志**:
- `IsPlayPhase = true`
- `PlayerActionsDisabled = false`
- `IsEnemyTurnStarted = false`

### 3.2 玩家可执行操作

在出牌阶段，玩家可以：
- 打出卡牌
- 使用药水
- 结束回合

### 3.3 卡牌打出流程

```
卡牌打出
├── ★ Hook.BeforeCardPlayed(combatState, cardPlay)
├── 执行卡牌效果
│   ├── 攻击
│   │   ├── ★ Hook.BeforeAttack(combatState, command)
│   │   ├── 执行攻击
│   │   └── ★ Hook.AfterAttack(combatState, command)
│   ├── 获得护盾
│   │   ├── ★ Hook.BeforeBlockGained(combatState, creature, amount, props, cardSource)
│   │   ├── 获得护盾
│   │   └── ★ Hook.AfterBlockGained(combatState, creature, amount, props, cardSource)
│   └── 施加能力
│       ├── ★ Hook.BeforePowerAmountChanged(combatState, power, amount, target, applier, cardSource)
│       ├── 改变能力层数
│       └── ★ Hook.AfterPowerAmountChanged(combatState, power, amount, applier, cardSource)
├── ★ Hook.AfterCardPlayed(combatState, choiceContext, cardPlay)
└── ★ Hook.AfterCardPlayedLate(combatState, choiceContext, cardPlay)
```

## 四、玩家回合结束阶段

### 4.1 回合结束触发

玩家点击"结束回合"按钮时：
```
SetReadyToEndTurn(player, canBackOut)
├── 添加玩家到准备列表
├── 触发 PlayerEndedTurn 事件
└── 检查是否所有玩家都准备好
    └── 是 → AfterAllPlayersReadyToEndTurn()
```

### 4.2 回合结束阶段一 (Phase One)

```
AfterAllPlayersReadyToEndTurn()
├── 设置 EndingPlayerTurnPhaseOne = true
├── 设置同步状态为 EndTurnPhaseOne
├── 等待动作队列清空
└── EndPlayerTurnPhaseOneInternal()
    ├── 等待解除暂停
    ├── 设置 IsPlayPhase = false
    ├── ★ Hook.BeforeTurnEnd(combatState, currentSide)
    ├── 检查胜利条件
    ├── 遍历玩家执行 DoTurnEnd
    │   ├── 球体队列回合结束前处理
    │   ├── 处理虚无卡牌（消耗）
    │   └── 处理回合结束手牌效果
    ├── ★ Hook.BeforeFlush(combatState, player)
    └── 生成校验和
```

### 4.3 回合结束阶段二 (Phase Two)

```
AfterAllPlayersReadyToBeginEnemyTurn()
├── 设置 EndingPlayerTurnPhaseTwo = true
├── 设置同步状态为 NotPlayPhase
├── 触发 AboutToSwitchToEnemyTurn 事件
└── EndPlayerTurnPhaseTwoInternal()
    ├── 处理手牌
    │   ├── 检查 ShouldFlush
    │   ├── 弃置非保留卡牌
    │   └── ★ Hook.AfterCardRetained(combatState, card) (保留卡牌)
    ├── 清理回合结束状态
    └── ★ Hook.AfterTurnEnd(combatState, currentSide)
```

### 4.4 切换到敌人方

```
SwitchFromPlayerToEnemySide()
├── 检查额外回合
│   └── 遍历玩家检查 ShouldTakeExtraTurn
├── 切换方 (SwitchSides)
│   ├── 玩家方 → 敌方
│   └── 敌方 → 玩家方 (回合数+1)
├── 遍历额外回合玩家
│   └── ★ Hook.AfterTakingExtraTurn(combatState, player)
├── 等待解除暂停
└── 开始下一回合 (StartTurn)
```

**关键Hook时序**:
```
BeforeTurnEnd
    ↓
BeforeFlush
    ↓
AfterCardRetained (保留卡牌)
    ↓
AfterTurnEnd
    ↓
AfterTakingExtraTurn (如果有额外回合)
```

## 五、敌人回合阶段

### 5.1 敌人回合执行

```
ExecuteEnemyTurn()
├── 执行额外动作（如果有）
├── 遍历所有敌人
│   ├── 获取敌人节点
│   ├── 执行意图 (PerformIntent)
│   ├── 执行回合 (TakeTurn)
│   ├── 等待解除暂停
│   └── 检查胜利条件
├── 生成校验和
└── 结束敌人回合 (EndEnemyTurn)
```

### 5.2 敌人回合结束

```
EndEnemyTurn()
├── 等待解除暂停
├── EndEnemyTurnInternal()
│   ├── ★ Hook.BeforeTurnEnd(combatState, currentSide)
│   ├── 清理回合结束状态
│   └── ★ Hook.AfterTurnEnd(combatState, currentSide)
├── 检查胜利条件
├── 切换方 (SwitchSides)
├── 等待解除暂停
└── 开始玩家回合 (StartTurn)
```

---

## 六、战斗结束阶段

### 6.1 胜利条件检查

```
CheckWinCondition()
├── 检查是否有待处理的失败状态
│   └── 是 → ProcessPendingLoss() → 结束
├── 检查是否战斗结束
│   ├── 所有主要敌人死亡
│   └── 没有Hook阻止战斗结束
└── 是 → EndCombatInternal()
```

### 6.2 战斗结束内部逻辑

```
EndCombatInternal()
├── 获取战斗状态和房间信息
├── 设置 IsInProgress = false
├── 设置 IsPlayPhase = false
├── 设置 PlayerActionsDisabled = false
├── 清空额外回合列表
├── 复活玩家（战斗结束前）
├── ★ Hook.AfterCombatEnd(runState, combatState, room)
├── 清空战斗历史
├── 房间战斗结束处理
├── 写入回放
├── 玩家战斗结束处理
├── ★ Hook.AfterCombatVictory(runState, combatState, room)
├── 清空悬停提示
├── 记录回合数
├── 检查Boss胜利条件
├── 标记房间预完成
├── 保存运行
├── 启用地图旅行
├── 更新进度
├── 检查成就
├── 保存进度文件
├── 多人游戏缩放模型处理
├── 触发 CombatWon 事件
├── 解除动作执行器暂停
├── 设置同步状态为 NotInCombat
├── 更新音乐轨道
└── 触发 CombatEnded 事件
```

**关键Hook时序**:
```
AfterCombatEnd
    ↓
AfterCombatVictory
```

## 七、完整Hook触发顺序

### 7.1 战斗开始序列

```
1. CombatSetUp (事件)
2. BeforeCombatStart
3. BeforeSideTurnStart (玩家方)
4. AfterTurnStart (每个玩家生物)
5. AfterBlockCleared (每个玩家生物)
6. AfterEnergyReset (每个玩家)
7. BeforeHandDraw (每个玩家)
8. ModifyHandDraw (每个玩家)
9. AfterModifyingHandDraw (每个玩家)
10. AfterPlayerTurnStart (每个玩家)
11. AfterSideTurnStart (玩家方)
12. BeforePlayPhaseStart (每个玩家)
```

### 7.2 玩家回合序列

```
出牌阶段:
- BeforeCardPlayed
- [卡牌效果相关Hook]
- AfterCardPlayed
- AfterCardPlayedLate

结束回合:
1. BeforeTurnEnd
2. BeforeFlush
3. AfterCardRetained (保留卡牌)
4. AfterTurnEnd
5. AfterTakingExtraTurn (如果有额外回合)
```

### 7.3 敌人回合序列

```
1. BeforeSideTurnStart (敌方)
2. AfterSideTurnStart (敌方)
3. [敌人执行意图和动作]
4. BeforeTurnEnd
5. AfterTurnEnd
```

### 7.4 战斗结束序列

```
1. AfterCombatEnd
2. AfterCombatVictory
3. CombatWon (事件)
4. CombatEnded (事件)
```

## 八、关键事件

### 8.1 CombatManager事件

| 事件 | 触发时机 |
|------|----------|
| `CombatSetUp` | 战斗设置完成时 |
| `CombatEnded` | 战斗结束时 |
| `CombatWon` | 战斗胜利时 |
| `CreaturesChanged` | 生物列表变化时 |
| `TurnStarted` | 回合开始时 |
| `TurnEnded` | 回合结束时 |
| `PlayerEndedTurn` | 玩家结束回合时 |
| `PlayerUnendedTurn` | 玩家取消结束回合时 |
| `AboutToSwitchToEnemyTurn` | 即将切换到敌人回合时 |
| `PlayerActionsDisabledChanged` | 玩家操作禁用状态变化时 |

## 九、状态标志说明

### 9.1 CombatManager状态

| 标志 | 说明 |
|------|------|
| `IsInProgress` | 战斗是否进行中 |
| `IsPlayPhase` | 是否在出牌阶段 |
| `IsEnemyTurnStarted` | 敌人回合是否已开始 |
| `PlayerActionsDisabled` | 玩家操作是否被禁用 |
| `EndingPlayerTurnPhaseOne` | 是否在回合结束阶段一 |
| `EndingPlayerTurnPhaseTwo` | 是否在回合结束阶段二 |
| `IsEnding` | 战斗是否即将结束 |
| `IsAboutToLose` | 是否即将失败 |

### 9.2 CombatState状态

| 属性 | 说明 |
|------|------|
| `RoundNumber` | 当前回合数 |
| `CurrentSide` | 当前行动方 (Player/Enemy) |
| `Allies` | 友方生物列表 |
| `Enemies` | 敌方生物列表 |
| `Creatures` | 所有生物列表 |
| `Players` | 所有玩家列表 |

## 十、数据收集建议

### 10.1 推荐监听的Hook

根据战斗日志Mod的需求，推荐监听以下Hook：

| 数据类型 | 推荐Hook |
|----------|----------|
| 战斗开始 | `BeforeCombatStart` |
| 战斗结束 | `AfterCombatEnd`, `AfterCombatVictory` |
| 回合开始 | `BeforeSideTurnStart`, `AfterSideTurnStart` |
| 回合结束 | `BeforeTurnEnd`, `AfterTurnEnd` |
| 伤害数据 | `BeforeAttack`, `AfterAttack`, `AfterDamageReceived` |
| 护盾数据 | `BeforeBlockGained`, `AfterBlockGained`, `AfterBlockBroken` |
| 卡牌数据 | `BeforeCardPlayed`, `AfterCardPlayed`, `AfterCardDrawn` |
| 能量数据 | `AfterEnergyReset`, `AfterEnergySpent` |
| 能力数据 | `BeforePowerAmountChanged`, `AfterPowerAmountChanged` |

### 10.2 数据收集时机

```
战斗初始化:
├── BeforeCombatStart → 初始化数据结构
├── CombatSetUp → 记录战斗基础信息

回合循环:
├── BeforeSideTurnStart → 记录回合开始
├── [各种游戏事件Hook] → 收集实时数据
└── AfterTurnEnd → 汇总回合数据

战斗结束:
├── AfterCombatEnd → 生成战斗报告
└── AfterCombatVictory → 保存战斗数据
```
