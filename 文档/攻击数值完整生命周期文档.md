## 一、核心数据结构

### 1.1 ValueProp - 伤害属性枚举

伤害属性决定了伤害如何被处理——是否可被格挡、是否触发能力效果、是否为动作伤害等。

```csharp
[Flags]
public enum ValueProp
{
    Unblockable = 2,   // 不可格挡：绕过护盾直接扣血
    Unpowered   = 4,   // 不触发能力效果：不触发"受到攻击时"类能力
    Move        = 8,   // 动作/移动：标记为攻击动作（区别于状态伤害）
    SkipHurtAnim = 16  // 跳过受伤动画
}
```

**预定义伤害属性组合**（`DamageProps` 静态类）：

| 属性名 | 值 | 含义 | 典型场景 |
|--------|-----|------|----------|
| `card` | `Move` | 普通卡牌攻击 | 打出攻击牌 |
| `cardUnpowered` | `Unpowered \| Move` | 不触发能力的卡牌攻击 | 某些特殊攻击 |
| `cardHpLoss` | `Unblockable \| Unpowered \| Move` | 卡牌导致的HP损失 | 诅咒/自伤 |
| `monsterMove` | `Move` | 怪物攻击 | 敌人回合攻击 |
| `nonCardUnpowered` | `Unpowered` | 非卡牌不触发能力伤害 | 状态效果伤害 |
| `nonCardHpLoss` | `Unblockable \| Unpowered` | 非卡牌HP损失 | 毒药/灾厄 |

**属性判断扩展方法**：

```csharp
public static bool IsPoweredAttack(this ValueProp props)
{
    return props.HasFlag(ValueProp.Move) && !props.HasFlag(ValueProp.Unpowered);
}

public static bool IsCardOrMonsterMove(this ValueProp props)
{
    return props.HasFlag(ValueProp.Move);
}
```

### 1.2 DynamicVar - 动态值基类

所有卡牌数值（伤害、格挡等）的基础类，管理基础值、附魔值和预览值三层状态。

```csharp
public class DynamicVar : IConvertible
{
    protected AbstractModel? _owner;
    private decimal _baseValue;       // 基础值（卡牌原始值）
    private decimal _enchantedValue;  // 附魔后的值
    private decimal _previewValue;    // 预览值（含Hook修改）

    public string Name { get; }
    public decimal BaseValue { get; set; }      // 最大 999,999,999
    public decimal EnchantedValue { get; set; }  // 附魔后值
    public decimal PreviewValue { get; set; }    // 最终预览值
    public bool WasJustUpgraded { get; protected set; }
    public int IntValue => (int)BaseValue;
}
```

**三层值的关系**：

```
BaseValue (基础值)
    │
    ▼ EnchantDamageAdditive / EnchantDamageMultiplicative
EnchantedValue (附魔值)
    │
    ▼ Hook.ModifyDamage
PreviewValue (预览值，即卡牌上显示的最终数值)
```

> **源码位置**: `src/Core/Localization/DynamicVars/DynamicVar.cs`

### 1.3 DamageVar - 固定伤害值

用于定义卡牌的固定伤害值（如"造成6点伤害"）。

```csharp
public class DamageVar : DynamicVar
{
    public const string defaultName = "Damage";
    public ValueProp Props { get; set; }

    public DamageVar(decimal damage, ValueProp props)
        : base("Damage", damage)
    {
        Props = props;
    }

    public override void UpdateCardPreview(CardModel card, CardPreviewMode previewMode,
        Creature? target, bool runGlobalHooks)
    {
        decimal num = base.BaseValue;

        // 1. 附魔修改
        EnchantmentModel enchantment = card.Enchantment;
        if (enchantment != null)
        {
            num += enchantment.EnchantDamageAdditive(num, Props);  // 加法
            num *= enchantment.EnchantDamageMultiplicative(num, Props); // 乘法
            if (!card.IsEnchantmentPreview)
                base.EnchantedValue = num;
        }

        // 2. Hook修改（预览时）
        if (runGlobalHooks)
        {
            num = Hook.ModifyDamage(card.Owner.RunState, card.CombatState,
                target, card.Owner.Creature, base.BaseValue, Props, card,
                ModifyDamageHookType.All, previewMode, out _);
        }

        base.PreviewValue = num;
    }
}
```

> **源码位置**: `src/Core/Localization/DynamicVars/DamageVar.cs`

### 1.4 CalculatedDamageVar - 计算型伤害值

用于伤害值需要动态计算的场景（如"基于手牌数造成伤害"），公式为：

```
最终伤害 = CalculationBase.BaseValue + CalculationExtra.BaseValue × 乘数
```

```csharp
public class CalculatedDamageVar : CalculatedVar
{
    public const string defaultName = "CalculatedDamage";
    public ValueProp Props { get; }
    public bool IsFromOsty { get; private set; }

    public decimal Calculate(Creature? target)
    {
        CardModel cardModel = (CardModel)_owner;
        decimal multiplier = (CombatManager.Instance.IsInProgress && cardModel.CombatState != null)
            ? _multiplierCalc(cardModel, target)
            : 0m;

        return GetBaseVar().BaseValue + GetExtraVar().BaseValue * multiplier;
    }

    protected override DynamicVar GetBaseVar()
        => ((CardModel)_owner).DynamicVars.CalculationBase;

    protected override DynamicVar GetExtraVar()
        => ((CardModel)_owner).DynamicVars.ExtraDamage;
}
```

**计算示例**（如 Body Slam）：

```
基础伤害 = CalculationBase.BaseValue (如 0)
额外伤害 = CalculationExtra.BaseValue (如 1)
乘数     = 玩家当前护盾值 (如 12)
最终伤害 = 0 + 1 × 12 = 12
```

> **源码位置**: `src/Core/Localization/DynamicVars/CalculatedDamageVar.cs`, `src/Core/Localization/DynamicVars/CalculatedVar.cs`

### 2.5 AttackContext - 攻击上下文

`AttackContext` 封装了 `BeforeAttack` / `AfterAttack` Hook 对，确保攻击生命周期完整。

```csharp
public sealed class AttackContext : IAsyncDisposable
{
    public static async Task<AttackContext> CreateAsync(CombatState combatState, CardModel cardSource)
    {
        AttackContext context = new AttackContext(combatState, cardSource);
        await Hook.BeforeAttack(combatState, context._attackCommand);  // ★ 攻击前Hook
        return context;
    }

    public async ValueTask DisposeAsync()
    {
        if (!_disposed)
        {
            _disposed = true;
            await Hook.AfterAttack(_combatState, _attackCommand);  // ★ 攻击后Hook
        }
    }
}
```

> **源码位置**: `src/Core/Commands/Builders/AttackContext.cs`

## 三、攻击执行阶段

### 3.1 AttackCommand.Execute 完整流程

```
AttackCommand.Execute(choiceContext)
│
├── 前置检查
│   ├── Attacker == null → 抛出异常
│   ├── CombatManager.IsOverOrEnding → 直接返回
│   ├── Attacker.IsDead → 直接返回
│   └── 无目标设置 → 抛出异常
│
├── ★ Hook.BeforeAttack(combatState, this)
│
├── ★ Hook.ModifyAttackHitCount(combatState, this, _hitCount) → attackCount
│
├── 循环 i = 0 到 attackCount-1
│   ├── 检查 Attacker.IsDead → 跳出循环
│   ├── 获取有效目标 (存活的)
│   ├── 有效目标为0 → 跳出循环
│   │
│   ├── [播放攻击者动画/特效] (首击或每击)
│   │   ├── _attackerVfx → VfxCmd.PlayOnCreatureCenter
│   │   ├── _customAttackerVfxNodes → AddChildSafely
│   │   ├── _attackerSfx → SfxCmd.Play
│   │   ├── _attackerAnimName → CreatureCmd.TriggerAnim
│   │   └── _afterAttackerAnim → await
│   │
│   ├── [播放命中音效]
│   │
│   ├── [确定本次攻击目标]
│   │   ├── 非随机 → 单目标或有效目标列表
│   │   └── 随机 → Rng.CombatTargets.NextItem(validTargets)
│   │
│   ├── [等待命中前延迟]
│   │
│   ├── [播放命中特效]
│   │
│   ├── [BeforeDamage回调]
│   │
│   └── ★ CreatureCmd.Damage(...)
│       └── (详见第四章)
│
├── CombatManager.Instance.History.CreatureAttacked(combatState, Attacker, results)
│
└── ★ Hook.AfterAttack(combatState, this)
```

### 3.2 伤害值确定

在 `Execute` 循环中，每次命中的伤害值确定逻辑：

```csharp
decimal damageAmount = (_calculatedDamageVar == null)
    ? _damagePerHit                          // 固定伤害值
    : _calculatedDamageVar.Calculate(singleTarget);  // 动态计算伤害值
```

**CalculatedDamageVar.Calculate 公式**：

```
damage = CalculationBase.BaseValue + CalculationExtra.BaseValue × multiplier(card, target)
```

其中 `multiplier` 是通过 `WithMultiplier` 注册的静态计算函数，由具体卡牌定义。

## 四、伤害计算阶段（核心管线）

### 4.1 CreatureCmd.Damage 完整流程

这是伤害系统的核心方法，处理从伤害修改到HP扣除的全部逻辑。

```
CreatureCmd.Damage(choiceContext, targets, amount, props, dealer, cardSource)
│
├── 前置检查
│   ├── dealer != null && dealer.IsDead → 返回空结果
│   └── targetList.Count == 0 → 返回空列表
│
├── 遍历每个目标 originalTarget
│   │
│   ├── ═══════ 阶段1: 伤害修改 ═══════
│   │   ├── ★ Hook.ModifyDamage(runState, combatState, originalTarget, dealer,
│   │   │       amount, props, cardSource, ModifyDamageHookType.All, None, out modifiers)
│   │   │   ├── [附魔修改] EnchantDamageAdditive + EnchantDamageMultiplicative
│   │   │   ├── [加法修改] ModifyDamageAdditive (遍历所有Hook监听者)
│   │   │   ├── [乘法修改] ModifyDamageMultiplicative (遍历所有Hook监听者)
│   │   │   └── [伤害上限] ModifyDamageCap (取最小上限)
│   │   └── ★ Hook.AfterModifyingDamageAmount(runState, combatState, cardSource, modifiers)
│   │
│   ├── ═══════ 阶段2: 受伤前通知 ═══════
│   │   └── ★ Hook.BeforeDamageReceived(choiceContext, runState, combatState,
│   │           originalTarget, modifiedAmount, props, dealer, cardSource)
│   │
│   ├── ═══════ 阶段3: 护盾处理 ═══════
│   │   └── creature.DamageBlockInternal(modifiedAmount, props)
│   │       ├── props.HasFlag(Unblockable) → blockedDamage = 0
│   │       └── 否则 → blockedDamage = min(Block, amount); Block -= blockedDamage
│   │
│   ├── ═══════ 阶段4: Osty前HP损失修改 ═══════
│   │   ├── unblockedDamage = max(modifiedAmount - blockedDamage, 0)
│   │   ├── ★ Hook.ModifyHpLostBeforeOsty(runState, combatState, originalTarget,
│   │   │       unblockedDamage, props, dealer, cardSource, out modifiers)
│   │   │   ├── ModifyHpLostBeforeOsty (遍历所有Hook监听者)
│   │   │   └── ModifyHpLostBeforeOstyLate (遍历所有Hook监听者)
│   │   └── ★ Hook.AfterModifyingHpLostBeforeOsty(runState, combatState, modifiers)
│   │
│   ├── ═══════ 阶段5: 伤害目标修改 ═══════
│   │   └── ★ Hook.ModifyUnblockedDamageTarget(combatState, originalTarget,
│   │           unblockedDamage, props, dealer)
│   │       └── 遍历所有Hook监听者 → 可能将伤害转移给Osty
│   │
│   ├── ═══════ 阶段6: Osty后HP损失修改 ═══════
│   │   ├── ★ Hook.ModifyHpLostAfterOsty(runState, combatState, unblockedDamageTarget,
│   │   │       unblockedDamage, props, dealer, cardSource, out modifiers)
│   │   │   ├── ModifyHpLostAfterOsty (遍历所有Hook监听者)
│   │   │   └── ModifyHpLostAfterOstyLate (遍历所有Hook监听者)
│   │   └── ★ Hook.AfterModifyingHpLostAfterOsty(runState, combatState, modifiers)
│   │
│   ├── ═══════ 阶段7: HP扣除 ═══════
│   │   └── unblockedDamageTarget.LoseHpInternal(unblockedDamage, props)
│   │       ├── willBeKilled = (CurrentHp > 0 && amount >= CurrentHp)
│   │       ├── damageAmount = min(amount, 999999999)
│   │       ├── CurrentHp = max(CurrentHp - damageAmount, 0)
│   │       └── 返回 DamageResult
│   │           ├── UnblockedDamage = 原HP - 新HP
│   │           ├── WasTargetKilled = willBeKilled
│   │           └── OverkillDamage = max(damageAmount - 原HP, 0)
│   │
│   ├── ═══════ 阶段8: 伤害目标重定向处理 ═══════
│   │   ├── 如果 originalTarget != unblockedDamageTarget
│   │   │   ├── 对 originalTarget 再次执行 ModifyHpLostAfterOsty (使用OverkillDamage)
│   │   │   └── 如果 originalTargetDamage > 0 → originalTarget.LoseHpInternal
│   │   └── 设置 BlockedDamage / WasBlockBroken / WasFullyBlocked
│   │
│   ├── ═══════ 阶段9: 视觉效果 ═══════
│   │   ├── CombatManager.History.DamageReceived (记录历史)
│   │   ├── NDamageNumVfx.Create (伤害数字特效)
│   │   ├── NHitSparkVfx.Create (击中火花特效)
│   │   ├── CreatureCmd.TriggerAnim("Hit") (受伤动画)
│   │   ├── SfxCmd.PlayDamage (受伤音效)
│   │   └── NGame.Instance.ScreenShake (屏幕震动)
│   │
│   └── (继续下一目标)
│
├── ═══════ 阶段10: 后置Hook ═══════
│   ├── 遍历所有 DamageResult
│   │   ├── WasBlockBroken → ★ Hook.AfterBlockBroken
│   │   ├── UnblockedDamage > 0 → ★ Hook.AfterCurrentHpChanged
│   │   ├── ★ Hook.AfterDamageGiven(choiceContext, combatState, dealer, result, props, target, cardSource)
│   │   ├── WasTargetKilled → 加入 killedCreatures 列表
│   │   └── 否则 → ★ Hook.AfterDamageReceived(choiceContext, runState, combatState, target, result, props, dealer, cardSource)
│   │
│   ├── ★ Kill(killedCreatures) (处理死亡)
│   └── await Cmd.CustomScaledWait(0.1f, 0.2f)
│
└── 返回 results
```

### 4.2 Hook.ModifyDamage 详解

这是伤害修改的核心方法，执行顺序严格遵循 **附魔 → 加法 → 乘法 → 上限** 的管线。

```
Hook.ModifyDamage(runState, combatState, target, dealer, damage, props,
                  cardSource, modifyDamageHookType, previewMode, out modifiers)
│
├── 1. 附魔修改 (Enchantment)
│   ├── if cardSource.Enchantment != null
│   │   ├── Additive:  num += EnchantDamageAdditive(num, props)
│   │   └── Multiplicative: num *= EnchantDamageMultiplicative(num, props)
│   │
│   └── 附魔修改示例:
│       ├── Sharp附魔: EnchantDamageAdditive = Amount (固定加成)
│       ├── Momentum附魔: EnchantDamageAdditive = ExtraDamage (动态加成)
│       └── Instinct附魔: EnchantDamageMultiplicative (乘法加成)
│
├── 2. 多目标预览优化
│   ├── 如果 target==null 且 previewMode==MultiCreatureTargeting
│   │   ├── 遍历所有 HittableEnemies
│   │   ├── 对每个敌人调用 ModifyDamageInternal
│   │   ├── 如果所有敌人修改后伤害相同 → 使用统一值
│   │   └── 否则 → 回退到对null目标调用
│   │
│   └── 否则 → 直接调用 ModifyDamageInternal
│
├── 3. ModifyDamageInternal (核心修改逻辑)
│   │
│   ├── [加法修改] ModifyDamageHookType.Additive
│   │   └── 遍历 runState.IterateHookListeners(combatState)
│   │       └── num += item.ModifyDamageAdditive(target, num, props, dealer, cardSource)
│   │           └── 默认返回 0m (AbstractModel基类)
│   │           └── 修改量 != 0 → 记录到 modifiers
│   │
│   ├── [乘法修改] ModifyDamageHookType.Multiplicative
│   │   └── 遍历 runState.IterateHookListeners(combatState)
│   │       └── num *= item.ModifyDamageMultiplicative(target, num, props, dealer, cardSource)
│   │           └── 默认返回 1m (AbstractModel基类)
│   │           └── 修改量 != 1 → 记录到 modifiers
│   │
│   └── [伤害上限] ModifyDamageCap
│       └── 遍历 runState.IterateHookListeners(combatState)
│           └── cap = min(cap, item.ModifyDamageCap(target, props, dealer, cardSource))
│               └── 默认返回 decimal.MaxValue
│               └── 如果 num > cap → num = cap, 记录到 modifiers
│
└── return Math.Max(0m, num)  // 最低为0
```

**伤害修改公式总结**：

```
modifiedDamage = max(0, min(
    (baseDamage + enchantAdditive + hookAdditive) × enchantMultiplicative × hookMultiplicative,
    damageCap
))
```

> **源码位置**: `src/Core/Hooks/Hook.cs` `ModifyDamage` 和 `ModifyDamageInternal` 方法

## 五、护盾处理

### 5.1 DamageBlockInternal

```csharp
public decimal DamageBlockInternal(decimal amount, ValueProp props)
{
    // 不可格挡伤害：护盾不吸收
    if (props.HasFlag(ValueProp.Unblockable))
        return 0m;

    // 计算护盾吸收量
    decimal blockedDamage = Math.Min(Block, amount);

    // 扣除护盾
    Block -= (int)blockedDamage;

    return blockedDamage;
}
```

**护盾处理规则**：

| 伤害属性 | 护盾是否吸收 |
|----------|-------------|
| `Move` (普通攻击) | ✅ 吸收 |
| `Unblockable \| Move` | ❌ 不吸收 |
| `Unblockable \| Unpowered` | ❌ 不吸收 |

> **源码位置**: `src/Core/Entities/Creatures/Creature.cs` `DamageBlockInternal` 方法

### 5.2 护盾状态判断

```csharp
// 护盾是否被打破（之前有护盾，现在归零）
bool wasBlockBroken = originalTarget.Block <= 0 && blockedDamage > 0m;

// 是否被完全格挡（有护盾吸收了伤害，且未格挡伤害为0）
bool wasFullyBlocked = !props.HasFlag(ValueProp.Unblockable)
    && (blockedDamage > 0m || originalTarget.Block > 0)
    && (int)unblockedDamage == 0;
```

## 六、HP扣除

### 6.1 LoseHpInternal

```csharp
public DamageResult LoseHpInternal(decimal amount, ValueProp props)
{
    // 判断是否会被击杀
    bool willBeKilled = CurrentHp > 0 && amount >= CurrentHp;

    int currentHp = CurrentHp;
    int damageAmount = (int)Math.Min(amount, 999999999m);

    // 扣除HP（最低为0）
    CurrentHp = Math.Max(CurrentHp - damageAmount, 0);

    return new DamageResult(this, props)
    {
        UnblockedDamage = currentHp - CurrentHp,  // 实际扣血量
        WasTargetKilled = willBeKilled,           // 是否被击杀
        OverkillDamage = willBeKilled
            ? Math.Max(damageAmount - currentHp, 0)  // 过量伤害
            : 0
    };
}
```

**关键计算**：

```
实际扣血 = 原HP - 新HP
过量伤害 = max(伤害量 - 原HP, 0)  (仅在击杀时)
```

> **源码位置**: `src/Core/Entities/Creatures/Creature.cs` `LoseHpInternal` 方法

当 `ModifyUnblockedDamageTarget` 将伤害目标从原始目标转移到其他生物（如Osty）时，需要特殊处理：

```

│
├── 对 unblockedDamageTarget 执行 LoseHpInternal → ostyResult

    ├── 第一个: ostyResult (Osty受到的伤害)
    └── 第二个: originalTargetResult (原始目标受到的溢出伤害)
```

## 十三、卡牌预览伤害计算

卡牌在手中显示的伤害值通过 `UpdateCardPreview` 计算，流程与实际伤害计算类似但不执行HP扣除：

```
│   └── Hook.ModifyDamage(runState, combatState, target, dealer,
│           base.BaseValue, Props, card, All, previewMode, out _)
│
└── PreviewValue = num  (卡牌上显示的数值)
```

**CardPreviewMode**：

## 十四、伤害数值流转总结

### 14.1 从卡牌定义到最终伤害的完整数值链

```
卡牌定义 (CardModel.DynamicVars)
│
├── DamageVar.BaseValue = 6                    // 卡牌基础伤害
│
├── [附魔修改]
│   ├── + EnchantDamageAdditive (如 Sharp +2)  // 6 + 2 = 8
│   └── × EnchantDamageMultiplicative          // 8 × 1.0 = 8
│
├── [Hook修改 - ModifyDamage]
│   ├── + ModifyDamageAdditive (如 力量 +3)    // 8 + 3 = 11
│   ├── × ModifyDamageMultiplicative           // 11 × 1.0 = 11
│   └── min(ModifyDamageCap)                   // min(11, MaxValue) = 11
│
├── modifiedAmount = 11
│
├── [护盾处理]
│   ├── 目标 Block = 4
│   ├── blockedDamage = min(4, 11) = 4
│   ├── Block = 4 - 4 = 0
│   └── unblockedDamage = 11 - 4 = 7
│
├── [HP损失修改 - BeforeOsty]
│   └── ModifyHpLostBeforeOsty → 7 (无修改)
│
├── [目标修改]
│   └── ModifyUnblockedDamageTarget → 原始目标 (无转移)
│
├── [HP损失修改 - AfterOsty]
│   └── ModifyHpLostAfterOsty → 7 (无修改)
│
├── [HP扣除]
│   ├── CurrentHp = 20 → 20 - 7 = 13
│   └── DamageResult:
│       ├── BlockedDamage = 4
│       ├── UnblockedDamage = 7
│       ├── OverkillDamage = 0
│       ├── WasBlockBroken = true (Block从4变为0)
│       ├── WasFullyBlocked = false
│       └── WasTargetKilled = false
│
└── [后置Hook]
    ├── AfterBlockBroken ✓
    ├── AfterCurrentHpChanged(creature, -7) ✓
    ├── AfterDamageGiven ✓
    └── AfterDamageReceived ✓
```

---

### 14.2 伤害数值关键公式

| 阶段 | 公式 | 说明 |
|------|------|------|
| 附魔后伤害 | `base + enchantAdd) × enchantMul` | 附魔修改 |
| Hook修改后伤害 | `max(0, min((damage + hookAdd) × hookMul, cap))` | Hook管线 |
| 护盾吸收 | `min(Block, damage)` | 不可格挡时为0 |
| 未格挡伤害 | `max(damage - blocked, 0)` | 需要扣HP的部分 |
| 实际扣血 | `min(hpLost, CurrentHp)` | 不超过当前HP |
| 过量伤害 | `max(hpLost - CurrentHp, 0)` | 击杀时溢出部分 |
