## 结构优化方案

### 1. 服务层重构

#### 当前问题

- 9 个 Service 文件都是静态类
- 服务之间无法共享状态或协作
- 静态方法难以测试和模拟
- 缺乏统一的服务生命周期管理

#### 优化方案

**方案 A：服务合并**

将相关服务合并为更大的服务类：

```
CombatService (合并前)
├── BeforeCombatStartService
├── AfterCombatEndService
├── BeforeSideTurnStartService
└── AfterTurnEndService

AttackService (合并前)
├── AfterDamageGivenService
├── AfterDeathService
└── PowerReceivedService
```

**方案 B：依赖注入**

引入服务定位器模式：

```csharp
// 基类
abstract class GameService
{
    protected readonly LogState _logState;
    protected GameService(LogState logState) => _logState = logState;
}

// 服务管理器
class ServiceLocator
{
    private static Dictionary<Type, GameService> _services;
    
    public static T GetService<T>() where T : GameService
    {
        return (T)_services[typeof(T)];
    }
    
    public static void Initialize(LogState logState)
    {
        _services = new Dictionary<Type, GameService>
        {
            [typeof(DamageService)] = new DamageService(logState),
            [typeof(CombatService)] = new CombatService(logState),
        };
    }
}
```

**推荐**：方案 B（依赖注入）

### 3. 引入事件系统

#### 当前问题

- Patch 层直接调用 Service
- Service 之间无法通信
- UI 刷新逻辑散落各处
- 违反开闭原则

#### 优化方案

**事件驱动架构**：

```
┌─────────────┐
│   Patch     │ 发布事件
└──────┬──────┘
       ↓
┌─────────────┐
│  EventBus   │ 分发事件
└──────┬──────┘
       ↓
┌─────────────┬─────────────┬─────────────┐
│  Service    │   State     │    View     │ 订阅事件
└─────────────┴─────────────┴─────────────┘
```

**事件定义**：

```csharp
enum GameEventType
{
    RunStarted,
    CombatStart,
    CombatEnd,
    TurnStart,
    TurnEnd,
    DamageGiven,
    Death,
    PowerReceived
}

interface IGameEvent
{
    GameEventType Type { get; }
}

class DamageGivenEvent : IGameEvent
{
    public GameEventType Type => GameEventType.DamageGiven;
    public Creature Dealer;
    public DamageResult Result;
    public Creature Target;
    public CardModel? CardSource;
}
```

**事件总线**：

```csharp
class EventBus
{
    private static Dictionary<GameEventType, List<Action<IGameEvent>>> _subscribers 
        = new();
    
    public static void Subscribe(GameEventType type, Action<IGameEvent> handler)
    {
        if (!_subscribers.ContainsKey(type))
            _subscribers[type] = new List<Action<IGameEvent>>();
        _subscribers[type].Add(handler);
    }
    
    public static void Unsubscribe(GameEventType type, Action<IGameEvent> handler)
    {
        if (_subscribers.TryGetValue(type, out var handlers))
            handlers.Remove(handler);
    }
    
    public static void Publish(IGameEvent gameEvent)
    {
        if (_subscribers.TryGetValue(gameEvent.Type, out var handlers))
        {
            foreach (var handler in handlers)
                handler(gameEvent);
        }
    }
}
```

**使用示例**：

```csharp
// Patch 层 - 只负责发布事件

{
    EventBus.Publish(new DamageGivenEvent

        Target = target

}
```

## 性能优化方案

### 1. UI 刷新策略优化（最高优先级）

#### 当前问题

- 每次数据变化都完整重建 UI
- `QueueFree()` + `new` 导致 GC 压力
- 高频事件触发过于频繁
- 每次刷新销毁所有子节点再重建

#### 性能分析

**当前实现**：

```csharp
private void Refresh()
{
    // 销毁所有子节点
    foreach (var child in _playerList.GetChildren())
    {
        child.QueueFree();  // 产生 GC
    }
    
    // 重新创建所有节点
    foreach (var playerData in players)
    {
        var row = BuildPlayerRow(playerData, index);  // 大量 new 操作
        _playerList.AddChild(row);
    }
}
```

**问题**：
- 4 个玩家 × 每个玩家 1 个 PanelContainer + 1 个 HBoxContainer + 5 个 Label = 28 个对象
- 每次刷新创建 28 个对象，销毁 28 个对象
- 高频事件（伤害、回合）触发频繁，每秒可能刷新 10+ 次

#### 优化方案 A：增量更新（推荐）

**核心思路**：只更新变化的行，不重建整个列表

```csharp
class AttackLogPanel : CanvasLayer
{
    private Dictionary<PlayerInfo, PanelContainer> _playerRows = new();
    private VBoxContainer _playerList;
    
    private void Refresh()
    {
        var players = GetRegisteredPlayers();
        var currentPlayerInfos = new HashSet<PlayerInfo>(players.Select(p => p.PlayerInfo));
        
        // 1. 移除已离开的玩家
        var toRemove = _playerRows.Keys
            .Where(info => !currentPlayerInfos.Contains(info))
            .ToList();
        
        foreach (var info in toRemove)
        {
            if (_playerRows.TryGetValue(info, out var row))
            {
                row.QueueFree();
                _playerRows.Remove(info);
            }
        }
        
        // 2. 更新或创建玩家行
        int index = 0;
        foreach (var playerData in players)
        {
            if (_playerRows.TryGetValue(playerData.PlayerInfo, out var existingRow))
            {
                // 更新现有行
                UpdatePlayerRow(existingRow, playerData, index);
            }
            else
            {
                // 创建新行
                var newRow = BuildPlayerRow(playerData, index);
                _playerList.AddChild(newRow);
                _playerRows[playerData.PlayerInfo] = newRow;
            }
            index++;
        }
    }
    
    private void UpdatePlayerRow(PanelContainer row, PlayerData playerData, int index)
    {
        // 只更新 Label 文本，不重建控件
        var labels = row.GetChildren().OfType<HBoxContainer>()
            .SelectMany(h => h.GetChildren().OfType<Label>())
            .ToList();
        
        // 更新伤害数据
        AttackLogViewUtils.GetPlayerLog(playerData.PlayerInfo, 
            out var turnLog, out var roomLog, out var runLog);
        AttackLogViewUtils.GetDamagePercent(playerData.PlayerInfo, out var damagePercent);
        
        // 找到对应的 Label 并更新
        // percentLabel.Text = $"{damagePercent:F1}%";
        // runDamageLabel.Text = $"{runLog?.RealDamageDealt ?? 0}";
        // ...
    }
}
```

**收益**：
- GC 分配减少 80%+
- 刷新耗时减少 60%+
- 内存占用更稳定

#### 优化方案 B：对象池

**核心思路**：复用 UI 组件，避免频繁创建销毁

```csharp
class PlayerRowPool
{
    private readonly Stack<PanelContainer> _pool = new();
    private readonly List<PanelContainer> _active = new();
    private const int INITIAL_SIZE = 6;
    
    public PlayerRowPool()
    {
        // 预创建对象
        for (int i = 0; i < INITIAL_SIZE; i++)
        {
            _pool.Push(CreateNewRow());
        }
    }
    
    public PanelContainer Get()
    {
        var row = _pool.Count > 0 ? _pool.Pop() : CreateNewRow();
        _active.Add(row);
        return row;
    }
    
    public void Return(PanelContainer row)
    {
        _active.Remove(row);
        _pool.Push(row);
        row.GetParent()?.RemoveChild(row);
    }
    
    public void ReturnAll()
    {
        foreach (var row in _active.ToList())
        {
            Return(row);
        }
    }
    
    private PanelContainer CreateNewRow()
    {
        // 创建空的玩家行模板
        return new PanelContainer { /* 配置 */ };
    }
}
```

**使用方式**：

```csharp
class AttackLogPanel
{
    private PlayerRowPool _rowPool;
    
    private void Refresh()
    {
        // 归还所有对象
        _rowPool.ReturnAll();

        foreach (var playerData in players)
        {
            var row = _rowPool.Get();
            UpdatePlayerRow(row, playerData);
            _playerList.AddChild(row);
        }
    }
}
```

**收益**：
- GC 分配减少 90%+
- 需要额外管理池生命周期

#### 优化方案 C：防抖机制（必须配合 A 或 B）

**核心思路**：合并高频刷新请求

```csharp
class AttackLogPanel : CanvasLayer
{
    private float _lastRefreshTime = 0;
    private float _refreshInterval = 0.1f;  // 100ms
    private bool _refreshRequested = false;
    
    public void RequestRefresh()
    {
        float currentTime = Time.GetTicksMsec() / 1000f;
        
        if (currentTime - _lastRefreshTime >= _refreshInterval)
        {
            // 立即刷新
            Refresh();
            _lastRefreshTime = currentTime;
        }
        else
        {
            // 标记需要刷新
            _refreshRequested = true;
        }
    }
    
    public override void _Process(double delta)
    {
        if (_refreshRequested)
        {
            float currentTime = Time.GetTicksMsec() / 1000f;
            if (currentTime - _lastRefreshTime >= _refreshInterval)
            {
                Refresh();
                _lastRefreshTime = currentTime;
                _refreshRequested = false;
            }
        }
    }
}
```

**配合事件系统**：

```csharp
// View 层订阅事件
EventBus.Subscribe(GameEventType.DamageGiven, _ => RequestRefresh());
EventBus.Subscribe(GameEventType.TurnEnd, _ => RequestRefresh());
EventBus.Subscribe(GameEventType.CombatEnd, _ => RequestRefresh());
```

**收益**：
- 高频事件合并，减少刷新次数
- 配合增量更新效果最佳

### 2. 计算结果缓存

#### 当前问题

- `GetDamagePercent()` 每次遍历所有玩家
- 多处重复调用 `GetPlayerLog()`
- 相同数据多次计算

#### 优化方案

**缓存层设计**：

```csharp
class CachedPlayerStats
{
    public AttackLogModel TurnLog;
    public AttackLogModel RoomLog;
    public AttackLogModel RunLog;
    public float DamagePercent;
    public int TotalDamage;
    public long CacheTimestamp;
}

class ViewCache
{
    private Dictionary<PlayerInfo, CachedPlayerStats> _statsCache = new();
    private bool _cacheValid = false;
    private long _cacheTimestamp = 0;
    
    public void Invalidate()
    {
        _cacheValid = false;
    }
    
    public CachedPlayerStats GetStats(PlayerInfo info)
    {
        if (!_cacheValid)
        {
            RebuildCache();
        }
        return _statsCache.TryGetValue(info, out var stats) ? stats : null;
    }
    
    private void RebuildCache()
    {
        var runLog = LogState.Instance.RunLog;
        if (runLog == null) return;
        
        var players = runLog.GetAllPlayers();
        int totalDamage = 0;
        
        // 第一遍：计算总伤害
        foreach (var player in players)
        {
            var stats = CalculatePlayerStats(player.PlayerInfo);
            _statsCache[player.PlayerInfo] = stats;
            totalDamage += stats.RunLog?.RealDamageDealt ?? 0;
        }
        
        // 第二遍：计算百分比
        foreach (var player in players)
        {
            if (_statsCache.TryGetValue(player.PlayerInfo, out var stats))
            {
                int playerDamage = stats.RunLog?.RealDamageDealt ?? 0;
                stats.DamagePercent = totalDamage > 0 
                    ? (float)playerDamage / totalDamage * 100f 
                    : 0f;
                stats.TotalDamage = totalDamage;
            }
        }
        
        _cacheValid = true;
        _cacheTimestamp = DateTime.Now.Ticks;
    }
    
    private CachedPlayerStats CalculatePlayerStats(PlayerInfo info)
    {
        var stats = new CachedPlayerStats();
        
        // 计算回合数据
        stats.TurnLog = AttackLogViewUtils.GetPlayerTurnLog(info);
        
        // 计算房间数据
        stats.RoomLog = AttackLogViewUtils.GetPlayerRoomLog(info);
        
        // 计算游戏数据
        stats.RunLog = AttackLogViewUtils.GetPlayerRunLog(info);
        
        return stats;
    }
}
```

**集成到 LogState**：

```csharp
class LogState
{
    private ViewCache _viewCache = new();
    
    public void InvalidateCache()
    {
        _viewCache.Invalidate();
    }
    
    public CachedPlayerStats GetCachedStats(PlayerInfo info)
    {
        return _viewCache.GetStats(info);
    }
}
```

**在数据变化时失效缓存**：

```csharp
// Service 层
public static void HandleDamageGiven(...)
{
    // 处理伤害逻辑
    // ...
    
    // 失效缓存
    LogState.Instance.InvalidateCache();
}
```

**收益**：
- 避免重复计算
- 刷新性能提升 30%+
- 数据一致性更好

### 4. 内存管理策略

#### 当前问题

- 历史数据无限累积
- 没有清理机制
- 长时间游戏内存增长

#### 优化方案

**限制历史数据量**：

```csharp
class SingleRunLogData
{
    private const int MAX_ROOM_HISTORY = 50;
    private Queue<SingleRoomLogData> _roomLogs = new();
    
    public void EnqueueRoomLogData(SingleRoomLogData data)
    {
        _roomLogs.Enqueue(data);
        
        // 超过上限时移除最旧的数据
        while (_roomLogs.Count > MAX_ROOM_HISTORY)
        {
            _roomLogs.Dequeue();
        }
    }
}

class SingleRoomLogData
{
    private const int MAX_TURN_HISTORY = 100;
    private Queue<SingleTurnLogData> _turnLogs = new();
    
    public void EnqueueTurnLogData(SingleTurnLogData data)
    {
        _turnLogs.Enqueue(data);
        
        while (_turnLogs.Count > MAX_TURN_HISTORY)
        {
            _turnLogs.Dequeue();
        }
    }
}
```

**保留摘要，丢弃详情**：

```csharp
class SingleRunLogData
{
    // 总是保留
    public AttackLogModel RunLogSum { get; } = new();
    
    // 只保留最近 N 个房间的详细数据
    public Queue<SingleRoomLogData> RecentRooms { get; } = new();
    
    // 记录总数
    public int TotalRoomCount { get; private set; }
    
    public void EnqueueRoomLogData(SingleRoomLogData data)
    {
        RunLogSum.Plus(data.RoomLogSum);
        TotalRoomCount++;
        
        RecentRooms.Enqueue(data);
        
        while (RecentRooms.Count > MAX_ROOM_HISTORY)
        {
            RecentRooms.Dequeue();
        }
    }
}
```

**收益**：
- 防止内存无限增长
- 长时间游戏也能稳定运行
- 保留关键统计数据

### 5. 数据结构优化

#### 当前问题

- `Queue` 无法随机访问历史数据
- `Creature` 作为字典键可能导致内存泄漏

#### 优化方案 A：历史数据改用 List

```csharp
class SingleTurnLogData
{
    private List<AttackLogModel> _attackLogs = new();
    private int _currentIndex = 0;
    
    public void Add(AttackLogModel model)
    {
        if (_currentIndex < _attackLogs.Count)
        {
            _attackLogs[_currentIndex] = model;
        }
        else
        {
            _attackLogs.Add(model);
        }
        _currentIndex++;
    }
    
    public void Clear()
    {
        _currentIndex = 0;
    }
    
    public AttackLogModel GetAt(int index) => _attackLogs[index];
    
    public IReadOnlyList<AttackLogModel> GetAll() => _attackLogs.AsReadOnly();
}
```

#### 优化方案 B：使用 Creature 唯一标识

```csharp
class RunLog
{
    // 改用 InstanceId
    private Dictionary<ulong, PlayerData> _creatureIdToPlayers = new();
    
    public void RegisterPlayer(Player player)
    {
        ulong creatureId = player.Creature.GetInstanceId();
        var playerData = new PlayerData(player);
        
        _creatureIdToPlayers[creatureId] = playerData;
    }
    
    public PlayerData GetPlayerByCreature(Creature creature)
    {
        ulong creatureId = creature.GetInstanceId();
        return _creatureIdToPlayers.TryGetValue(creatureId, out var data) ? data : null;
    }
}
```

**收益**：
- 避免潜在的内存泄漏
- 支持随机访问
- 更安全的数据管理
